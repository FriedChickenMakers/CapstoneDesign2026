미션용 별도 BGM을 추가하거나 기존 곡 위에 다른 음악을 겹치지 않는다.
기존 BGM의 미션 화면 용도가 그대로 유지된다. 이야기 음성의 파일·재생기도
변경하지 않는다. 운영체제 카메라 촬영음과
시스템 알림음도 앱의 효과음으로 중복 재생하지 않는다. 회전·확대·스크롤,
텍스트 입력, 실습 시간의 매초, 호흡의 매 주기에는 효과음을 넣지 않는다.

정확한 편집 과정, 길이·피크·RMS를 기록한다. 원문 라이선스와 제작자 고지는
같은 폴더의 `Kenney-License.txt`, `THIRD_PARTY_AUDIO.txt`에 보존한다.
9개 효과음은 mono 44.1 kHz PCM16, 합계 약 547 KB이며, 짧은 효과의
재생 지연을 줄이도록 PCM/DecompressOnLoad/Preload로 가져온다.

## 재생과 설정 규칙

- `GardenSfxPlayer`만 효과음 음량을 소유한다. `capstone.sfx.volume`은 0–1,
  초기값은 1이며 100%도 각 효과에 설정한 조용한 기본 게인을 사용한다.
- 배경 음악 슬라이더와 저장 키, 기존 음악 소스 두 개, AudioListener는
  그대로 사용한다. 효과음은 별도의 2D AudioSource 5개 풀로 재생하며
  음악 소스·곡·시간대·페이드·전체 Listener 음량을 변경하지 않는다.
- 0%는 진행 중인 효과도 즉시 정지한다. 음량을 올려도 과거 효과는 재생하지 않는다.
  드래그 중 음량은 즉시 적용하고 저장은 250ms 묶음 처리하며,
  설정 이탈·앱 중지·종료에서 남은 변경을 저장한다.
- 효과음 슬라이더 조작을 마쳤을 때 한 번 미리 듣는다. 배경 음악 슬라이더의
  기존 동작은 변경하지 않는다. 미리보기/Editor 렌더링은 실제 저장·소리를 만들지 않는다.
- 버튼음은 75ms, 같은 의미의 효과음은 140ms 간격을 둔다.
  성공/실패 효과가 나는 클릭에서는 일반 클릭음을 중복으로 겹치지 않는다.
- 화면 재렌더링이나 완료 화면 재진입은 달성음의 조건이 아니다.
  성장 효과는 연출 중단·백그라운드 전환 시 정지하며 다시 돌아와도 이어 울리지 않는다.
- 내부의 짧은 움직임 축소 경로에서는 회오리·변화음을 생략하고 마지막 완료음만 낸다.
  짧아진 연출이 효과음의 잔향을 중간에 자르지 않도록 한다.
- Android 키보드가 유발하는 포커스 이벤트만으로 효과음을 중단하지 않는다.
  실제 앱 일시정지는 모든 효과를 정지한다. 데스크톱 포커스 상실도 정지한다.
- 전체 초기화는 효과음 설정도 기본값으로 돌리고 이전 저장 대기 작업을 지운다.
  초기화 과정에서 삭제한 설정 키를 다시 만들지 않는다.

음원 로딩은 첫 실행에서 기존 형식의 `preloadAudioData` 위치 오류를 발견하여
Unity 6의 `AudioImporter` v8 / `defaultSettings.preloadAudioData`로 수정한 뒤
9개 모두 실제 Importer 검사를 통과했다. 슬라이더 조작 중 앱 이탈 후 남는
미리 듣기 입력도 해제하도록 수정하고 Android 키보드 포커스와 구분해 검사했다.
첫 통합 검사 실행은 앞선 검사 보고서가 있는 공용 시험 디렉터리를 안전 장치가
거부했다. 검증 도구가 단계별 새 저장소를 쓰게 바꾼 뒤 16개 모두 통과했다.

증거는 무시되는 로컬 `artifacts/mission-art-quality-20261111/` 아래
`app-audio-20261112-v01`(BGM·구매·일일·정원·성장)과
`app-audio-20261112-v02`(최종 효과음·설정·통합·화면)에 보존한다.
두 BGM 파일·프로필·재생기 SHA256은 작업 시작/종료가 일치한다.
효과음 재생 중 기존 음악 클립·소스 게인·설정·Listener가 동일하고 재생 위치가
계속 증가하는 것도 Play 모드에서 확인했다. 이야기 음성과 기존 재생기도 수정하지 않았다.

Android 실기기의 오디오 지연·블루투스·통화 인터럽트와 실제 스피커/이어폰을
통한 청감 검사는 이번 작업에서 실행하지 않았다. Android 포커스/일시정지는
합성 수명주기 검사이며 실제 기기 검증을 대신하지 않는다.
미리 듣기 파일은 `artifacts/audio-sources-20261112/review-preview.wav`에 있으며
클릭 → 뒤로 → 시작 → 회오리 → 변화 → 달성 → 구매 → 기록 저장 → 오류 순서다.
