# P03–P28 안내 화면 개선

## 범위와 사용자 동작

P01/P02에서 확정한 `GUIDED_MISSION_VISUAL_RULES_20261109.md`를 남은 모든 현재 버전 P 미션에 적용한다. 소개에는 기존 미션 이름과 개요를 유지한다. 이후에는 제목·반복 미션명을 없애고, 행동 하나를 짧은 본문으로 안내한다. 본문 22·소개 제목 30의 중앙 정렬, 실제 줄높이 측정, 중앙 피벗과 큰 그림/하향 여유를 사용한다. 일반 화면은 한 화면에 담고, 선택/입력 내용이 긴 경우만 하단 영역을 스크롤한다.

P03–P07의 기존 준비·선택·안내 3장·실습·돌아보기 흐름을 유지한다. P08–P28은 기존 단계와 조건부 경로를 유지한다. 도움말은 최대 세 문장을 한 화면에 담고 한 번의 중앙 클릭/이전으로 해당 실습에 복귀한다. 이야기 글 보기는 실제 이야기 원문을 여러 장으로 읽는 기존 기능이며, 도움말과 달리 페이지를 합치거나 원문을 축약하지 않는다.

M 미션과 과거 버전 세션은 대상이 아니다. 카탈로그 ID/버전·선택지·필수 답변·분기·권장 시간·오디오·대기·저장·성장·코인 정책은 변경하지 않는다. 기기/사용자 저장본과 물리 마우스를 사용하지 않고, 커밋·푸시하지 않는다.

## 구현 책임

- `FocusGuidedPracticeContent` / `FocusBasicSlideContent`: 표시할 간결한 안내. 전후 문구와 보존 조건은 `P03_P28_COPY_20261109.md`에 기록한다.
- `FocusPracticeIllustration`: P03–P28의 미션 주제와 현재 단계·선택에 따른 비입력 벡터 그림. 프레임 애니메이션·센서·저장과 독립적이다. 공통 면/선 렌더와 그림 모티프를 재사용하지만 미션 주제·실루엣을 구분한다.
- `WeekOneQuestDemo.PracticeIllustrations`: 투명한 중앙 클릭 영역, 현재 단계/선택 전달, 주변 배경 테마.
- `GuidedFocusPractice` / `BasicFocusSlides`: 소개 이후 제목 제거, 큰 글자/그림 배치, 한 화면 도움말, 기존 정책 명령 호출. P26의 실제 `help` 단계와 도움말 오버레이 `guide-help`를 구분한다.
- 현재 버전 완료 화면은 해당 미션의 새 그림과 저장된 실습 선택을 사용한다. P18은 실습 중 마지막으로 선택한 대상, P12는 경험, P26은 도움 종류를 유지한다. 기록 확인 화면에서는 삭제한 제목 대신 본문이 어떤 저장 항목을 확인하는지 설명하고 현재 확인 중인 값으로 그림을 표시한다. 저장된 제목/답변은 변경하지 않는다.

P08–P28은 88 높이 입력란 전체가 보이도록 기존 측정형 배치의 최소 답변 높이를 100으로 지정한다. P03–P07은 86, P02는 기존 100을 유지한다. 오류 알림·긴 소개·이야기 본문이 있으면 그림 크기를 조절해 겹침을 피한다.

## 주요 위험과 검증

| 위험 | 확인 방법 |

| 새 그림이 입력을 가로채거나 잔류 | 비레이캐스트 그림, 투명 클릭 영역·현재 key에 의한 재생성, 실제 드래그·역행 픽셀 검사 |

| 도움말 통합으로 시간·초안·오디오 초기화 | 기존 시간 정지/재진입/실패 복구 및 소리 재생 경로 검사 |
| 분기/필수 선택/대기/보상 변경 | Guided/Basic/Daily/순수 상태 검사로 실제 완료와 중복 방지 확인 |
| M 또는 과거 세션 변경 | 기존 M 전체 페이지 digest와 비교, 현재 실행에서 과거 세션 복원 검사 |

검증 증거는 이번 작업의 `artifacts/all-p-guidance-20261109/`에 별도로 저장한다. 과거 화면은 비교 기준으로만 사용하며, 이번 성공 결과는 새 실행으로 확인한다.

## 구현 검토

- 도메인/카탈로그/저장 형식은 수정하지 않았다. 현재 버전의 표시 경로에만 새 안내와 그림을 연결했다.
- P26의 기록 확인은 도움 유무와 도움 종류, P28은 이번 실습·다음 주 실습·시간대를 각각 짧게 설명해 제목 삭제로 인한 의미 손실을 보완했다.
- 선택에 따라 손 씻기/설거지, 걷기/앉기, 이야기 듣기 경로와 실습 대상 그림이 달라진다. 선택되지 않은 행동을 그림이 임의로 확정하지 않도록 검토한다.
- 독립 읽기 검토에서 P01/P02 전용 분기, M/구형 세션 경로, 도움말 복귀와 저장 단계 보존을 확인했다. 실제 화면 배치는 별도 GPU 실행으로 판정한다.
- 돌아보기 답변을 실습 대상 선택으로 오인하지 않도록 표시용 조회를 분리했다. P19 소리 경로에서 감상/자유입력/저장 실패를 거쳐도 산 그림으로 바뀌지 않는 검사를 추가했다. P28의 항목별 검토 그림도 해당 저장값을 따른다.

## 비교 기준

초기 `basic01`의 옛 `mission-icon-layout-20261109/basic02` 비교는 M 완료 화면의 기존 ‘기록으로 이동’ 변경 때문에 실패했다. 17개 완료 화면 모두 그 버튼 문구/텍스트 노드 이름만 달랐고, 이번 P 변경의 차이가 아니었다. 제품을 옛 화면으로 되돌리지 않았다.

이번 작업 직전에 보관한 UI 파일 4개를 합성 캐시에만 복원해 `m-baseline01`을 새로 실행했다. 파일 출처/해시는 `m-baseline-provenance.json`, 캐시 소스 보존은 `m-baseline01/baseline-preservation.json`에 기록했다. M 경로가 참조하지 않는 새 P 그림/문구 파일은 비교에 영향을 주지 않는다. 이후 현재 제품 소스를 다시 복사한 실제 실행에서 106개 M 화면 digest를 전부 비교했다. 실제 프로젝트 파일/사용자 저장본은 이 과정에서 복원하거나 교체하지 않았다.
