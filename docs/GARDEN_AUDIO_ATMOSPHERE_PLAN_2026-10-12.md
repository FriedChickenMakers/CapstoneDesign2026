# 배경음악·정원 시간 디버그·하늘 개선 계획과 완료 결과

최종 구현 `021385e`를 A7에 설치·검증하고 원격 브랜치에 push했다. 섬 연결, 세계 방향의 태양·달, 안개, 시간 디버그, 음악 검증을 완료했다. 원본 기기 데이터와 화면 설정도 보존·복구했다. A7 회전 성능은 약 20fps 수준이라는 제한이 남아 있으며 아래에 측정 범위를 구분한다.

## 범위와 순서

1. 시작 상태를 검토하고 개인정보 검사 후 현재 upstream에 먼저 push한다.
2. 제공된 음악을 앱에 추가하고 홈·활동·설정별 트랙을 지정할 수 있는 재생 구조를 만든다. 현재는 제공된 한 곡을 사용하며 탭 이동 때 같은 곡이 다시 시작되지 않아야 한다. 앱이 배경으로 가면 재생을 멈추고 복귀와 음소거를 처리한다.
3. 설정 아래에 별도 UI 디버그 화면을 만든다. 24시간 원형 슬라이더로 정원 시각을 바꾸고 실제 시간으로 복귀할 수 있게 한다. 정원 조명에만 영향을 주며 활동 날짜·건강 기록·알림 예약은 바꾸지 않는다. 재실행 시 실제 시간으로 시작한다.
4. 밤 하늘과 환경광을 어둡게 조정한다. 재개 시 추가된 A7 피드백에 따라 구름의 도형 윤곽과 수평 띠를 제거하고, 공간에 퍼진 안개·연기와 느린 이동으로 바꾼다. 모바일 비용과 섬을 가리는 면적을 제한한다.
5. 다양한 시간대·화면 비율의 원본 렌더를 Vision으로 확인하고, 시간 다이얼·탭·뒤로가기·음악 수명주기와 기존 활동 동작을 검증한다. Android 빌드 및 가능한 A7 설치 검증 후 데이터를 보존하고 임시 기기 설정을 복구한다.
6. 공개 변경과 라이선스·음원 메타데이터를 검토하고 worktree 및 staged 개인정보 검사를 통과한 뒤 커밋·push한다. 원격 HEAD가 최종 로컬 HEAD와 같은지 확인한다.

Quota 잔여가 5% 미만으로 확인되면 사용자 지시에 따라 작업과 기기 설정을 안전하게 정리하고 현재 검증·미완료 항목을 기록한 뒤 pause한다. 비공개 기기 기록·원본 캡처는 무시되는 `artifacts/`에만 보관한다.

## 1차 검증과 이전 일시정지 기록

- 시간 다이얼은 경계·분 정밀도 단위 검사 7/7, 실제 EventSystem Play 15/15를 통과했다. 세 화면 비율의 설정·디버그 상단/하단을 Vision으로 확인했고 고정 제목·조작부·탭은 스크롤 전후 동일하다. 원본은 비공개 `artifacts/evolution-20261012/ui-debug/play2/`에 있다.
- 음악 Play 23/23을 통과했다. 제공곡의 재생 위치 전진과 0이 아닌 PCM 출력, 같은 곡의 탭 이동 연속성, 한 개 Listener, 포커스·일시정지 순서, 음소거·복귀, 다른 곡으로의 교차 페이드와 빠른 전환을 확인했다. 음소거 검사는 DSP 명령 전달 뒤 재생 위치 정지를 확인했다. Android 키보드 포커스 정책은 Editor 합성 검사이며 실제 스피커 청취·IME 검증과 구분한다. 결과는 비공개 `artifacts/music-review/play-validation/music-validation.json`에 있다.
- 밤 하늘과 달빛, 구름의 최종 렌더 13장을 Vision으로 확인했다. 구름 합성에서 RenderTexture 알파가 깎여 밝은 UI 배경이 새는 결함과 내부 명암의 직선 경계를 수정했다. 낮/밤 밝기 비교·24개 이동·실제 그림자·불투명 RT 알파 등 10개 검사 묶음이 통과했다. 최종 원본과 측정은 비공개 `artifacts/evolution-20261012/garden/atmosphere-final-pass/`에 보관한다.
- A7에 연결해 앱 실행·업데이트 전 private 기록·환경설정·정원 저장 백업을 완료했다. Quota 잔여가 5%에 도달한 시점에 추가 기기 작업을 시작하지 않고 화면 꺼짐·밝기·자동 밝기를 원래 값으로 복구·검증했다. 앱 실행·업데이트·MOCK 진입은 수행하지 않았다. 새 APK 설치와 실제 Android 음악·시간 디버그 검증은 남아 있다. 비공개 `a7/audio-atmosphere-pending.json`에 복구 완료와 미설치 상태를 구분해 보존한다.

## 이전 Quota 조건에 따른 일시정지

잔여 4%를 확인해 사용자의 조건에 따라 작업을 정리했다. Android 빌드는 네이티브 컴파일 단계에서 중단했으며 성공한 새 APK로 취급하지 않는다. Editor 검증이 완료된 소스·음악 자산·문서를 저장하고 개인정보 검사 후 현재 upstream에 동기화한다. 기기의 임시 설정은 모두 복구됐다.

재개 시 `scripts/build-android.sh`로 Android 빌드를 완료한 뒤, 사전 백업을 보존하면서 A7에 데이터 유지 설치한다. 시간 다이얼의 낮·밤/실시간 복귀와 뒤로가기, 실제 IME·백그라운드 전환 시 음악, 음소거 설정 복원을 확인한다. 새로운 기기 세션의 원래 화면 설정을 기록·복구한 뒤 최종 결과를 갱신하고 push한다.

## 재개 후 검증

- A7 설치본은 앞선 baseline 빌드였고 새 음악·시간 디버그 소스가 들어 있지 않았다. 재접속 시 원본 화면 설정을 기록하고 신규 사전 백업 후 격리 MOCK에서 홈 회전·하부·설정 7장을 촬영했다. 기존 화면의 수평 구름과 태양 위치 보정을 확인했다. LIVE 저장 바이트가 같은지 검증하고 MOCK과 임시 화면 설정을 정리한 뒤 새 빌드를 기다렸다.
- 섬은 기존 초원판·경사 가장자리 전체에 하부를 이어 붙인 단일 폐쇄 메시다. 상부·가장자리의 153개 면, 40개 배치 Transform, grass 재질 구획을 보존했다. 130개 용접 위치·384개 모서리·256개 삼각형의 닫힘·방향·연결·자기 교차와 실제 씬 참조 검사를 통과했다. 환경 2종과 방문자 12종의 접지·충돌 검사 및 yaw 4방향 × pitch 5개(-85~85도)의 20장 검토를 완료했다. 원본은 `artifacts/solid-island-final-20261012/`다. 수정은 `17b0fd3`으로 커밋·push하고 원격 일치를 확인했다.
- 설정의 UI 디버그를 배경음악 다음 독립 카드로 옮기고 ‘홈·정원 시간대 조절’로 기능을 표시했다. 새 진입의 실제 EventSystem 클릭과 원형 다이얼·뒤로가기·시간 격리 Play 15/15, 세 화면 비율의 진입/디버그 상하단 9장 Vision을 통과했다. 고정 영역은 스크롤 전후 픽셀이 같다. 원본은 `artifacts/evolution-20261012/ui-debug/resume-play/`다.
- 태양·달은 native skybox의 세계 방향과 광원 방향을 공유한다. 최종 렌더에서 태양 yaw -20/0/+20도의 중심이 화면 x 0.63/0.50/0.37로 이동하고, ±90/180도에서는 사라지며 360도 복귀의 픽셀 차이는 0이다. 달도 바라볼 때 378픽셀, 반대 시선에서 0픽셀로 확인했다. off-axis orthographic에서도 동작한다.
- 안개는 카메라에 붙던 세 줄의 구름 대신 세계 공간의 24개 밀도 입자를 사용한다. 카메라 회전 시 위치가 변하지 않고 60초 동안 24개 모두 수평·수직 이동한다. 낮의 가시성을 보완하고 on/off 비교 하한 검사도 추가했다. 낮은 31만 픽셀, 밤은 34.8만 픽셀에서 RGB 3단계 이상의 차이가 있으며, 섬 중앙은 읽을 수 있다. 통합 환경 검사 10개도 통과했다. 밤/낮 평균 밝기 32.61/187.19, 실제 그림자 39,169픽셀 및 불투명 렌더 알파를 확인했다. 최종 근거는 `artifacts/evolution-20261012/atmosphere-world-final/`다. 기기 성능·청취 결과로 확대하지 않는다.

## A7 설치 및 실제 입력 검증

Android 빌드가 성공했고 첫 검증 APK(`a40f2d19…`)를 기존 데이터 유지 방식으로 설치했다. 설치된 APK의 SHA-256이 빌드 산출물과 일치했다. 새 백업을 확보한 뒤 설치 전후와 격리 MOCK 검증 종료 후를 비교했다. 센서 기록 42개, 환경설정 5개, LIVE 정원 저장 3개는 원본과 바이트가 같았다. Android의 비센서 `profileInstalled` 마커는 이 비교에서 구분했다. 임시 MOCK·오디오 trace를 기기에서 정리하고, 음악 설정의 원래 키 부재 상태와 화면 꺼짐·밝기·자동 밝기를 복구해 readback으로 확인했다.

- 실제 설정에서 UI 디버그 진입, 원형 다이얼의 00:00/12:00, 실제 시간 복귀, Android 뒤로가기, 00:00 고정 후 앱 재시작 시 실제 시간 초기화를 확인했다. 09:00 태양과 21:00 달도 시점을 옮겨 노출·시야 이탈을 확인했다.
- 낮·밤의 정면·옆면·밑면을 원본 PNG로 검토했다. 섬 내부로 하늘이 관통하는 틈은 없었고 안개는 전후 깊이에 따라 섬을 부드럽게 가렸다. 설정과 시간 다이얼에 글자 겹침·클리핑은 발견하지 못했다. 파일 이름에 noon이 있지만 시간 변경 전 찍힌 17·18번은 정오 증거에서 제외하고, 20~23번을 사용했다.
- 음악은 실제 Android의 비영 PCM과 재생 위치 증가, 음소거 4.63초 동안 출력 0·위치 정지, 해제 후 재개, 같은 곡의 탭 이동 연속성을 확인했다. 실제 키보드를 연 3.56초 동안에도 재생이 이어졌다. 이 기기에서는 해당 IME 입력 시 blur 이벤트가 발생하지 않았으므로 blur 이벤트 전달까지 검증했다고 주장하지 않는다. 앱을 배경에 둔 4.80초 동안 위치가 같고 복귀 후 이어졌다. 이는 엔진 출력 검사이며 물리 스피커 청취가 아니다.
- 오디오 진단을 끈 별도 실행에서 10초 준비 후 20초 정지 화면은 817프레임, median 16.67 ms / p95 50.04 ms였다. 약 10초 회전은 257프레임, median 49.96 ms / p95 66.73 ms로 약 20fps 수준이었다. 회전 성능은 여전히 개선 여지가 있으며 60fps 검증으로 취급하지 않는다. 이전 비통제 세션과 개선율을 비교하지 않는다. ADB 단계 경계에는 1초 미만의 측정 오차가 있다.

## 최종 원반 보정과 설치 완료

직교 카메라의 native skybox는 정사각형 기준 방향을 사용해, 세로 RT에서는 원반도 세로로 늘어났다. 화면 위치를 고정하지 않고 하늘 광선의 가로 비율을 최종 표시 비율에 맞춘 뒤 세계 방향으로 되돌린다. 공유 RT의 크기와 카드의 표시 비율이 다를 수 있으므로, 해당 카메라 렌더 직전에 `camera.aspect`를 하늘 재료에 전달한다. 콜백 안에서는 Render·투영행렬·RT를 변경하지 않는다.

- 중심 원반의 세로·가로·정사각형 표준/off-axis 12개, 공유 RT 카드 4개는 모두 가로/세로 비율 1.00이었다. 실제 홈 4개도 정상적인 비축 투영 범위를 통과했다. 원본을 Vision으로 검토했으며 기존 방향·시야 이탈·360도 복귀·광원·안개 회귀도 통과했다. 근거는 `artifacts/evolution-20261012/sky-shape-final-pass/`다.
- 최종 APK는 `artifacts/evolution-20261012/a7-atmosphere-aspect-build/build/capstone-mockup.apk`, SHA-256은 `66f8652afa11930b24e35f4c5c178e429f9df00782fbcef6650243a4dbd823b3`이다. 빌드 성공 후 공개 입력 962개가 그대로인지 확인했고, 새 백업 뒤 A7에 데이터 유지 설치해 기기의 APK 해시도 확인했다.
- 최종 A7 원본의 태양은 64×70, 달은 57×62픽셀로, 이전 약 0.53/0.55의 과도한 가로/세로 비율이 약 0.91/0.92로 수정됐다. 이는 섬을 피한 비축 시점의 측정값이며 중심 원형 검사와 구분한다. 반대 방향에서는 태양 원반이 없고 달 장면에는 작은 별점만 남았다. root의 원본 Vision 검토도 완료했다.
