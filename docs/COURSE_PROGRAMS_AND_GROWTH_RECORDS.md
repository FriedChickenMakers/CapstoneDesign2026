# 2·4·8주 활동과 성장 기록

2026-10-26 QA 구현. 2주와 4주를 완결된 시작 선택지로 제공한다. 기존 8주 48회 전체를 더 빠르게 수행하도록 요구하지 않는다. 세 과정은 마음챙김 원리를 참고한 앱 자체 활동이며, 짧은 과정의 임상적 동등성이나 효과를 검증했다는 의미는 아니다.

## 기간별 구성

| 선택 | 활동 수 | 흐름 | 완료 보상 합계 |
| --- | ---: | --- | ---: |
| 2주 | 12 | 감각·호흡·몸 → 일상·움직임·멈춤 → 소리·생각 → 돌봄·지원·유지 계획 | 영양제 60개 |
| 4주 | 24 | 몸과 일상 → 멈춤과 생각 관찰 → 생각과 대응 → 변화 신호·지원·유지 계획 | 영양제 120개 |
| 8주 | 48 | 기존 여덟 주차의 학습과 반복 연습 | 영양제 240개 |

2주는 한 모금 알아차리기, 자연스러운 숨, 몸 살펴보기, 일상 행동, 움직임, 잠시 멈추기, 소리 관찰, 상황과 생각 구분, 기운을 주는 활동, 나를 돕는 계획, 다시 할 실습, 생활 속 실습 이어가기 순서다. 마지막 활동에는 생활 속 계기와 놓친 날 다시 시작하는 계획이 포함된다.

4주는 같은 기초에서 시작해 생각에 이름 붙이기, 몸·감정 관찰, 현재로 돌아오기, 다음 행동 선택, 선택적인 개인 사례를 연습한다. 마지막 주에는 변화 신호·대응·지원, 선호 실습과 유지 계획을 연결한다. 즐거운·불편한 경험 기록은 모든 기간에서 별도로 사용할 수 있다.

기간은 권장 일정이다. 참여하지 않은 날에 초기화·패널티·기한 만료가 없으며, 새 활동은 하루 한 개와 달력 주당 최대 여섯 개다. 완료 시점의 일일 회차를 사용한다. 여러 기간을 오가더라도 이 한도는 합산한다.

새 활동 완료는 영양제 5개, 기존 성장 구매는 10개로 유지한다. 복습·기간 선택·기간 전환에는 추가 보상이 없다. 새 저장에서 다른 구매를 하지 않는 경우 2·4주 모두 두 활동마다 성장 구매가 가능하며, 여섯 번째 완료 보상으로 세 번째 성장을 확정하면 기존 씨앗→새싹→봉오리→개화 흐름을 완주 전에 볼 수 있다. 실제 잔액·구매 선택에 따라 시점은 달라지며 자동 성장이나 별도 완료 보너스를 만들지는 않는다.

## 선택·전환·저장

- 신규 사용자는 활동 탭에서 2주·4주·8주 순서로 선택하고, 구성과 보존 안내를 읽은 뒤 확정한다.
- 기존 저장은 선택한 8주 코스로 이행한다. 기존 `course:MBCT01`부터 `course:MBCT48`, `MbctNextOrder`, `MbctCompletedIds`를 변경하거나 재해석하지 않는다.
- 새 영구 ID는 `course:MBCT2W01`–`12`, `course:MBCT4W01`–`24`다. 각 코스의 진도는 독립적으로 저장하며 활동의 원래 분류를 절차적 식물 외형에 연결한다.
- 진행 중·일시정지·선택 중인 활동이 있으면 기간 전환을 막는다. 완료하거나 참여 종료 후 바꿀 수 있다. 전환 시 기존 활동·감정·계획·영양제·정원을 보존한다.
- 다른 기간으로 갔다가 돌아오면 이전 진도에서 이어간다. 코스를 마치면 해당 기간 완료를 표시하고 복습 또는 다른 기간 선택을 제공한다.
- 다른 기간에서 이미 배운 활동은 복습할 수 있지만, 미완료 순차 활동을 새로 시작하려면 그 기간을 먼저 선택해야 한다.
- 프로그램 필드가 없는 저장은 8주를 유지한다. 새 필드와 짧은 코스 세션을 이해하지 못하는 오래된 APK로의 다운그레이드 호환성을 보장하지 않는다.

## 성장 이력과 원래 활동 연결

성장 미리보기에서 `함께 기억할 활동`을 선택할 수 있다. 사용자가 직접 선택한 완료·종료 활동 ID만 연결한다. 최근 활동, 날짜, 잔액을 이용해 영양제의 원인이나 감정을 추정하지 않는다. 선택하지 않아도 성장할 수 있다.

성장 확정 시 구매 요청 ID, 식물 ID, 실제 확정 시각, 성장 전후 값, 선택한 활동 ID를 영양제 차감·Recipe 변경과 같은 저장 트랜잭션으로 남긴다. 저장 실패 시 모두 유지하고, 동일 요청 재시도는 한 번만 처리한다. 재시도로 이미 저장한 연결을 바꾸지 않는다.

`참여 기록 → 식물 성장 기록 → 성장 상세 → 그때의 활동과 감정 보기`에서 원본 기록으로 이동한다. 연결하지 않은 성장은 연결 없음으로 표시한다. 과거 버전의 성장에는 당시 시각이나 출처를 새로 만들지 않으며, 기존 정원은 보존하고 상세 연결 기록이 없음을 알린다.

## 주간·누적 기록

`참여 기록 → 이번 주와 지금까지`에서 현지 월요일 이후와 전체 기간을 구분해 활동 완료·참여 종료 횟수와 경험 유형별 기록 개수를 표시한다. 복습도 참여 횟수에 포함하고, 진행 중 활동을 완료로 세지 않는다. 경험 유형은 사용자가 입력한 즐거움·불편함·중립·잘 모르겠음이며 빈 기록을 임의의 감정으로 분류하지 않는다. 빈도에서 우울 상태·개선 정도·치료 효과를 추정하지 않는다.

## 검증 경계

`./scripts/test-mbct.sh`는 세 기간의 전체 완료·재실행·보상·개화, 기간 간 일일·주간 제한, 진행 중 전환 거절, 기존 48회 보존, 실패 원자성, 성장 이력의 명시 연결·연결 없음·중복·마이그레이션, 주간/전체 요약 경계를 검사한다. 기존 상태 회귀는 `./scripts/test-local-state.sh`로 검사한다. 모든 입력은 합성 자료다. Unity 통합·화면·실기기 결과는 별도 실행 근거로 기록한다.

`LocalLoopValidation`은 2·4·8주 각각 첫 두 활동 완료→영양제 적립→성장 연결 선택·해제·취소→저장 실패 재시도→성장 기록에서 원래 감정·메모 열기와 뒤로가기를 검사한다. 빈 기록·선택 없는 성장·탭 이탈 시 미확정 구매 취소, 주간/누적 요약과 조회 시 저장 내용 불변도 포함한다. `TabConsistencyCapture.CaptureRemaining`에는 성장 연결·기록·요약의 빈 화면, 목록, 상세, 저장 실패를 세 해상도로 확인할 상태가 있다.
