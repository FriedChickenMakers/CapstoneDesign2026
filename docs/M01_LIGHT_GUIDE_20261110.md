# M01 주변 밝히기 안내

## 범위와 기준

현재 작업 브랜치 `codex/combine-garden-20261107`에서 M01부터 P 안내 규칙을 적용한다. M02–M17, P 미션, 저장 버전·성장·코인·일일 한도는 이번 변경 범위가 아니다. 별도 브랜치 통합은 수행하지 않는다.

## 사용자 흐름

| 화면 | 안내 | 그림과 조작 |
|---|---|---|
| 소개 | 주변 밝히기 / 커튼이나 조명으로 주변에 빛을 조금 더해요. | 창가와 조명이 있는 방. 아이콘을 눌러 시작 |
| 방법 | 지금 편한 방법 하나를 골라요. | 커튼 열기·조명 켜기 중 선택하면 해당 안내로 이동. 아이콘으로 선택 없이 공통 안내도 가능 |
| 커튼 실행 | 커튼을 조금 열어 주변에 빛을 더해요. | 열린 커튼과 들어오는 햇빛. 실제 행동 후 아이콘을 눌러 완료 |
| 조명 실행 | 가까운 조명을 켜 주변에 빛을 더해요. | 켜진 조명과 빛의 퍼짐. 실제 행동 후 아이콘을 눌러 완료 |
| 공통 실행 | 커튼을 조금 열거나 조명을 켜요. | 두 방법의 밝아진 방. 새로운 필수 선택은 없음 |
| 도움말 | 커튼과 조명 중 하나면 돼요. / 눈부시지 않을 만큼만 밝게 해요. / 지금 어렵다면 나갔다 이어해요. | 한 화면. 아이콘 또는 이전으로 원래 안내 복귀 |

소개에만 제목을 표시한다. 본문 22·제목 30, 중앙 정렬, 큰 그림과 중앙 피벗, 반응형 한 화면 구성을 기존 `FocusGuidedSlideLayout`으로 제공한다. 이전은 안내 단계 안에서 이동하며 나가기는 기존 임시 저장 후 미션 화면으로 돌아간다. 연결선·빛 효과는 현재 그림 단계만으로 생성한다.

## 설계와 저장 계약

- `WeekOneQuestDemo.M01Light`는 표시 페이지와 선택한 안내 방법만 관리한다. `M01LightIllustration`은 화면 단계에 해당하는 그림만 그린다. 기존 서비스가 세션 시작, 완료, 성장·재화 원자 저장을 소유한다.
- 기존 M01의 단일 `light` 단계, 빈 답변, 권장 시간 없음, 선택 입력 없음 계약을 그대로 사용한다. 소개·방법 전환에서는 완료나 보상을 발생시키지 않는다.
- 커튼/조명 선택은 선택적 화면 안내이며 기록에 새 답변을 추가하지 않는다. 동일 UI의 이전·도움말·나가기 후 이어하기에서는 유지한다. 앱을 다시 시작해 불러온 미완료 세션은 방법 안내부터 안전하게 이어간다.
- 구버전 세션은 기존 화면을 유지한다. 새 저장 필드·이관·독립 지갑은 없다.
- 화면 root·세션·revision으로 오래된 버튼 콜백을 차단한다. 마지막 확인은 기존 저장 실패 안내와 재시도 경로를 사용한다. 초기화·디버그 종료 시 표시 상태도 초기화한다.

## 검증 계획 및 결과

별도 합성 Unity 프로젝트에서 320×568, 360×640, 390×844 화면을 렌더하고 실제 UI raycast로 조작한다. 소개/분기/도움말/이전·잔류효과/드래그 취소, 저장 실패·재시도·재진입·중복 완료, 기존 P 및 M02–M17 회귀, 비개발 플레이어 스크립트 컴파일을 확인한다. 실제 사용자 저장본과 원본 Unity, 연결 기기를 조작하지 않는다.

Unity 화면 검사 합계 48개 그룹·44,447 assertions PASS. M01은 세 해상도에서 커튼/조명/공통 안내, 도움말·이전의 실제 그림 복원, 드래그 취소, 오래된 콜백 차단, 나가기·재진입, 시작·확인·완료 저장 실패와 재시도, 성장 1회·50코인 1회, 일일 한도, 활동 일지 이동, 구버전 v2/v3 보존을 확인했다.

소개·선택·커튼·조명·도움말·완료·작은 화면의 저장 실패 PNG를 직접 열어 가독성과 겹침을 확인했다. 실제 제품 UI를 합성 저장소와 독립 GPU RenderTexture에 렌더한 결과이며 원본 Unity의 마우스나 창을 조작하지 않았다. 세 실행의 원본 소스 hash 비교는 모두 불일치 0, 기존 Unity 프로세스 유지 확인도 PASS였다.

첫 `basic01`에서는 새 검사의 합성 코스 선택 누락과 실제 존재하지 않는 M01 v1을 요구한 전제로 5그룹이 실패했다. 일반 사용 흐름처럼 코스를 선택하고 실제 과거 버전 v2/v3를 검사하도록 fixture를 정정했다. 제품 코드를 바꿔 실패를 우회하지 않았으며 `basic02`에서 전체를 새로 실행했다.

Android 실기기 설치·터치·성능 검사는 수행하지 않았다. 기존 `GardenPreview.renderTexture` 로컬 변경은 보존하고 게시에서 제외한다. M02–M17 안내 구체화는 후속 범위다.
