# M01 주변 밝히기 안내

## 범위와 기준

2026-11-10 `codex/combine-garden-20261107`에서 M01부터 P 안내 규칙을 적용했다. 2026-11-11 로컬 `main` 통합에서는 이 안내를 최신 `misssion`의 v5 동작과 합치며, v4 M01 저장본도 같은 안내를 사용한다. M02–M17, P 미션, 저장 버전·성장·코인·일일 한도는 M01 표현 개선으로 바꾸지 않는다.

## 사용자 흐름

| 화면 | 안내 | 그림과 조작 |
|---|---|---|
| 소개 | 주변 밝히기 / 커튼이나 조명으로 주변에 빛을 조금 더해요. | 창가와 조명이 있는 방. 아이콘을 눌러 시작 |
| 방법 | 지금 편한 방법 하나를 골라요. | 커튼 열기·조명 켜기 중 선택하면 해당 안내로 이동. 아이콘으로 선택 없이 공통 안내도 가능 |
| 커튼 실행 | 커튼을 조금 열어 주변에 빛을 더해요. | 열린 커튼과 들어오는 햇빛. 실제 행동 후 아이콘을 눌러 완료 |
| 조명 실행 | 가까운 조명을 켜 주변에 빛을 더해요. | 켜진 조명과 빛의 퍼짐. 실제 행동 후 아이콘을 눌러 완료 |
| 공통 실행 | 커튼을 조금 열거나 조명을 켜요. | 두 방법의 밝아진 방. 새로운 필수 선택은 없음 |
| 도움말 | 커튼과 조명 중 하나면 돼요. / 눈부시지 않을 만큼만 밝게 해요. / 지금 어렵다면 나갔다 이어해요. | 한 화면. 아이콘 또는 이전으로 원래 안내 복귀 |

소개에만 제목을 표시한다. 본문 22·제목 30, 중앙 정렬, 큰 그림과 중앙 피벗, 반응형 한 화면 구성을 기존 `FocusGuidedSlideLayout`으로 제공한다. 이전은 안내 단계 안에서 이동하며 나가기는 기존 임시 저장 후 미션 화면으로 돌아간다. 하단의 ‘미션 넘기기’는 최신 공통 확인 창을 열고, 확정하면 미완료로 종료하며 성장·코인을 지급하지 않는다. 연결선·빛 효과는 현재 그림 단계만으로 생성한다.

## 설계와 저장 계약

- `WeekOneQuestDemo.M01Light`는 표시 페이지와 선택한 안내 방법만 관리한다. `M01LightIllustration`은 화면 단계에 해당하는 그림만 그린다. 기존 서비스가 세션 시작, 완료, 성장·재화 원자 저장을 소유한다.
- 기존 M01의 단일 `light` 단계, 빈 답변, 권장 시간 없음, 선택 입력 없음 계약을 그대로 사용한다. 소개·방법 전환에서는 완료나 보상을 발생시키지 않는다.
- 커튼/조명 선택은 선택적 화면 안내이며 기록에 새 답변을 추가하지 않는다. 동일 UI의 이전·도움말·나가기 후 이어하기에서는 유지한다. 앱을 다시 시작해 불러온 미완료 세션은 방법 안내부터 안전하게 이어간다.
- v4·v5 M01은 동일한 단일 `light`/`prepare` 계약으로 새 안내를 사용한다. v2·v3 M01은 기존 화면을 유지한다. 새 저장 필드·이관·독립 지갑은 없다.
- 시간 제한 없는 `prepare` 단계이므로 화면 표시나 방법 선택만으로 실제 실습 시작 시각을 만들어내지 않는다. 마지막 행동 확인은 기존 `AdvanceFocus` 완료 경로로 처리한다.
- 화면 root·세션·revision과 확인 창 상태로 오래된 버튼 콜백을 차단한다. 마지막 확인은 기존 저장 실패 안내와 재시도 경로를 사용한다. 초기화·디버그 종료 시 표시 상태와 최신 미션 조절 콜백을 함께 초기화한다.

## 검증 계획 및 결과

별도 합성 Unity 프로젝트에서 320×568, 360×640, 390×844 화면을 렌더하고 실제 UI raycast로 조작한다. 소개/분기/도움말/이전·잔류효과/드래그 취소, 저장 실패·재시도·재진입·중복 완료, 기존 P 및 M02–M17 회귀, 비개발 플레이어 스크립트 컴파일을 확인한다. 실제 사용자 저장본과 원본 Unity, 연결 기기를 조작하지 않는다.

Android 실기기 설치·터치·성능 검사는 수행하지 않았다. 당시 `GardenPreview.renderTexture` 로컬 변경은 보존하고 게시에서 제외했다. M02–M17 안내 구체화는 후속 범위다.
