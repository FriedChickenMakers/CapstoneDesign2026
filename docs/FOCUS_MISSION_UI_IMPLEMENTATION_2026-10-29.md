# 집중 미션 UI 구현 · 2026-10-29

## 적용 범위

Figma의 메인 미션 화면과 4개 예시를 Unity에 반영했다. 기본 미션은 P23·P10·P25, 추천 추가 미션은 M03이다. 미션 화면에서는 탐색 메뉴를 숨기고, 단계별 안내와 중앙 아이콘 및 수행 동작에 집중하도록 구성했다. 기존 정원 화면과 정원 조작은 유지한다.

기본 과정은 **P23 → P10 → P25를 4번 반복하는 12회 순서**다. 완료한 기본 미션과 M03은 내 과정의 저장된 기록에서 돌아보고 복습할 수 있다. 이전에 저장한 기록도 삭제하지 않는다.

하단 탐색은 **홈 · 미션 · 내 과정**으로 통일한다. 홈은 기존 정원이며, 설정 진입은 홈 오른쪽 위의 임시 버튼으로 제공한다. 설정 화면에서도 하단 세 탭의 목적지는 동일하다. 미션 수행·감정·입력·완료 화면은 기존 집중 흐름대로 하단 탭을 숨긴다.

정원과 미션 화면은 같은 하단 탐색 컴포넌트를 사용한다. 정원의 기존 활동 요약 카드는 숨기고, 미션 아이콘 위에 오늘 수행 가능한 기본·추가 미션이 남으면 `!`, 모두 마쳤으면 `✓` 배지를 표시한다. 잠긴 미래 기본 미션과 선택한 복습은 미완료 수에 포함하지 않는다. 날짜가 바뀌면 오늘 상태로 갱신한다.

정원의 상단은 불투명한 패널 없이 큰 식물 이름·날짜·작은 영양제 수치를 카메라 배경 위에 표시하며, 정원 조명의 낮·밤에 맞춰 검은색·흰색으로 바꾼다. 이름에는 ‘오늘의’ 접두어를 붙이지 않는다. 아직 종이 확정되지 않은 씨앗은 현재 활동 프로필과 동일한 종 선택 규칙으로 예상 이름을 표시하며 저장된 종을 바꾸지는 않는다. 하단의 성장 단계·진행도 패널은 이전 크기와 위치로 복원한다. 날짜는 앱의 적용 날짜를 사용하므로 설정에서 날짜를 넘기면 함께 바뀐다. ‘보기 +’ 메뉴 없이 휴대폰의 두 손가락 벌리기·모으기와 컴퓨터 마우스 휠로 확대·축소한다. 한 손가락·마우스 드래그 회전은 유지하며, 버튼 위의 입력은 정원 확대·축소에 사용하지 않는다. 기본 배율은 정원 전체 보기이고 확대 범위는 기본 대비 0.5–2.25배다. 카메라 조작은 저장된 식물이나 미션 진행에 영향을 주지 않는다.

실습의 마지막 동작 이후에는 **공통 감정 선택 → 한 줄 기록 → 저장·보상 → 미션 완료**로 연결한다. 개별 미션마다 감정 화면을 별도로 복제하지 않는다.

390×844 기준 배치를 가용 화면에 맞춰 축소·확대한다. 임시 Figma 주소를 실행 중에 불러오지 않는다. 아이콘은 원본 SVG와 그 PNG 변환본을 프로젝트에 포함했으며, 원본 비율과 투명도를 유지한다.

## 저장과 재개

- 미션 ID·번호·제목·설명, 기본/추가 구분, 과정 순서, 복습 여부를 저장한다.
- 단계별 안내 제목·본문·선택/입력·생략 여부·수정 시각·확인 시각을 저장한다.
- 선택 감정, 메모, 시작·종료 시각, 실제 지급 영양제를 저장한다.
- 기본 미션과 추가 미션의 진행 중 기록을 각각 보존한다. 앱을 다시 열거나 닫기 후 돌아와도 이어서 수행할 수 있다.
- 완료 저장 실패 시 작성 내용과 진행 상태를 유지한다. 재시도로 중복 완료·중복 보상이 생기지 않도록 처리한다.
- 기본 미션의 해당 순서와 M03의 당일 보상은 중복 지급하지 않는다. 복습은 기록만 추가한다. 완료 화면에는 실제 지급 결과를 표시한다.

Unity 에디터는 별도의 `editor-mission-preview` 저장 공간을 사용하며 이전 기기·개발 기록을 초기값으로 가져오지 않는다. 미리보기 안에서 직접 수행한 기록은 재생을 다시 시작해도 유지한다. 처음 상태로 다시 확인하려면 재생을 멈춘 뒤 **Capstone Mockup → Start Fresh Mission Preview**를 사용한다. 매번 별도 저장 공간을 만들며 이전 기록은 삭제하지 않는다. 기기 앱의 저장 경로와 기존 기록 복원 동작은 유지한다.

기본 미션의 당일 완료, 주간 제한으로 인한 대기, 전체 과정 완료는 서로 다른 문구로 표시한다. 주간 대기일에는 ‘다음 주에 이어가요’로 안내한다.

설정의 **미션 관리 → 새로고침**은 수행 기록·선택/입력·감정·메모·과정 진도를 초기화한다. 정원 외형·성장·구매 내역·영양제와 적용 날짜는 유지하며, 초기화 성공 후에는 진행 중 화면의 입력 초안도 비운다. **다음 날로 넘기기**는 앱의 미션 날짜를 하루 진행시키고 다음 일일 미션을 열며, 적용 날짜를 저장해 재시작 후에도 유지한다. 휴대폰 시스템 날짜와 건강 데이터 원본은 변경하지 않는다. 기존 건강 기록 갱신은 별도의 **건강 기록 동기화** 버튼으로 제공한다. 저장 실패 시에는 기존 미션 기록과 날짜를 유지한다.

P25의 선택 입력과 공통 메모에서는 Android의 실제 가용 창 높이를 읽어 키보드 위에 입력란과 입력 마치기 버튼을 배치한다. 글자 크기를 유지하며, 키보드가 닫히면 원래 Figma 배치로 되돌린다.

## 확인 범위

상태 저장·재시작·순서·보상·복습·저장 실패 시나리오의 자동 검사를 수행했다. Unity의 분리된 미리보기와 합성 데이터로 화면 버튼 연결, 4개 미션 수행, 24개 감정 선택, 뒤로 가기, 기록 보존, 실패 후 재시도, 기록 열기와 복습을 확인했다. 버튼 중앙의 터치 판정과 주요 화면 캡처의 글자·아이콘·버튼 표시를 점검했다. 키보드가 가리는 높이별 입력·완료 버튼 배치 계산을 검사하며, Editor와 Android 조건의 런타임 코드를 각각 컴파일했다.

이 검증은 실제 사용자 기록을 사용하지 않는다. Android 실기기의 터치 판정, 키보드, 앱 종료·복귀와 화면 크기별 확인은 후속 QA 범위다.
