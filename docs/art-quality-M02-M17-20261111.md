# M02–M17 그림 품질 전수 검토

2026-11-11 사용자 요청으로 현재 `AdditionalMissionIllustration`과 기존 실제 Unity 화면을 전수 검토했다. 검토 기준 화면은 `artifacts/all-m-guidance-20261111/v06/additional/`의 각 미션 390×844 실행 화면이다. 이 화면은 변경 전 비교 자료이며 이번 변경의 성공 증거가 아니다. 이번 새 컴파일·렌더·동작 검사는 상위 통합 검증에서 별도 실행한다.

범위는 벡터 그림뿐이다. 미션의 문구·단계·저장·선택지·완료·성장·재화·조작·배치를 변경하지 않는다. 사용자 선택이나 실제 감정을 추측해 그림을 바꾸지 않는다. 기존 명시적 ‘잘 모르겠어요’ 답변만 중립 표현과 연결한다.

## 공통 문제와 적용

- 반투명 원을 네 개의 끝이 둥근 곡선으로 그려 접합부가 네 점처럼 진하게 보였다. `Ring`을 안팎 가장자리에 안티앨리어싱이 있는 연속 띠로 바꿨다. 특히 M02 관찰 원, M12 확대경, M17 호흡 원의 점이 사라진다.
- 곡선 두 개가 만나는 열린 화살촉은 작은 화면에서 뭉치거나 짧은 가지처럼 보였다. 둥근 곡선 몸체와 일정한 비율의 채운 화살촉으로 통일했다. 화살표 경로·행동 의미는 그대로 두었다.
- 공통 인물의 목이 길고 몸통·손이 단순한 도형처럼 보였다. 머리와 몸의 비율, 목·옷깃 연결, 겹친 옷감, 소매와 손의 경계를 다듬었다. 이 변경은 M05/M07/M09/M17에 적용된다.
- 재질의 차이가 단순한 색 차이에 그쳤다. 각 사물의 실제 구조를 설명하는 테두리·반사·접합·내부 면을 추가했다. 무관한 별·반짝임·추가 버튼은 만들지 않았다.

## 검증 경계

변경 전 실제 화면 16종을 열어 검토했다. 코드 공백 검사는 통과했다. 새 Unity 컴파일·선택별 렌더·소형 화면·효과 복원·원본 데이터 보존 결과는 상위 통합 검증에 기록하며, 여기서 실행하지 않은 검사를 성공으로 표시하지 않는다. 커밋·푸시는 하지 않았다.
