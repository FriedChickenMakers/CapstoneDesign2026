## 후반 활동의 기기 UI 검증

실제 저장본과 분리된 `garden-mock`에 완료된 코스의 합성 fixture를 넣고 MOCK 모드에서 복습 UI를 터치한다. 완료 진도 48/48은 fixture의 초기 조건이며 A7에서 8주 동안 새 추천 활동을 완료했다는 뜻이 아니다. 각 활동의 단계 이동과 선택 입력 건너뛰기, 완료 저장 및 복습 보상 0을 별도로 확인한다.

48개 활동, 147개 안내 단계의 터치 이동과 완료 저장을 모두 확인했다. 각 완료 세션의 활동 ID·단계 수·완료 상태를 기기 저장본과 대조했으며 복습 보상은 계속 0이었다. 일상 행동의 이전 선택 재사용, 불편한 경험 기록, 긴 기록에서 아래쪽 생각 항목까지 터치 스크롤하는 것도 확인했다.

검증 도중 짧은 ADB 연속 터치가 일부 누락되어 선택을 재시도했다. 항목마다 실제 저장 상태를 확인한 뒤 통과로 기록했으며, 일상 사용의 터치 반응 속도·프레임률을 정량 검증한 것은 아니다.

## 검증 자료와 범위

코드 저장소의 `artifacts/mbct-a7-20261003/`에 기기·APK 정보, 실제 전후 저장본, 결과 JSON, 단계 화면과 실행 로그를 저장한다. 화면 검증과 저장·보상 동작을 확인한 결과이며 임상 효과, 장기간 사용, 다른 Android 기기, 건강 센서의 정확도를 입증하지 않는다. 실제 주간 6일 경계와 48회 새 추천 진도는 앞서 진행한 합성 로직 검증 범위다.

검증 종료 후 A7을 LIVE 모드의 정원 화면으로 복귀시켰다. 실제 저장 파일은 MOCK 검증 전후 동일하며, 이번 검증에서 새로 만든 기기 MOCK 폴더와 임시 fixture는 증거를 저장한 후 제거했다. 최신 APK와 LIVE 검증에서 작성한 테스트 참여·경험·계획 기록은 유지한다.
