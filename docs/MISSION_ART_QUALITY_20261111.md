# 전체 P/M 미션 그림 품질 개선 — 2026-11-11

## 요청과 범위

사용자가 기본 P01–P28, 추가 M01–M17의 아이콘과 장식 선·화살표·보조 이미지를 전수 검토하고 코드에 개선을 반영하도록 요청했다. 사용자 목표는 짧은 안내와 함께 현재 행동을 그림만으로도 구별하고, 이전·도움말·선택 변경 후에도 해당 단계와 일치하는 그림을 보는 것이다.

- 소개 제목, 실습 중 짧은 안내, 큰 중앙 아이콘, 아이콘으로 진행, 이전/나가기/넘기기, 한 화면 도움말을 유지한다.
- 미션 단계, 저장 형식, 성장, 코인, 하루 제한, 카메라와 실제 사용자 데이터는 변경 범위가 아니다.
- 실제 코드의 벡터 그림을 개선한다. 외부 이미지·카메라·재질·네트워크 의존성은 추가하지 않는다.
- 미선택/불확실 답변에 임의의 감정·실습·긍정 결과를 배정하지 않는다.

## 표시 책임과 동작 계약

기존 5개 그림 컴포넌트는 화면 상태에 맞는 메시만 만든다. 컨트롤러가 기존 저장 답과 현재 입력을 읽어 P27의 생활 계기/활동, P28의 다음 활동/시간을 별도로 전달한다. 그림 컴포넌트는 저장 서비스나 보상 정책을 호출하지 않는다. 현재 실습과 미래 계획을 구분하고, 다른 미션으로 전환할 때 표시 문맥을 비운다.

1. 단계 진입: 현재 미션·단계·선택에 맞는 그림을 표시하고 장식은 입력을 가로채지 않는다.
2. 이전/도움말 복귀: 원래 단계의 그림을 정확히 복원하며 이전 강조를 누적하지 않는다.
3. 선택 수정/재진입: 저장 또는 현재 입력의 조합을 반영하며 다른 계기·활동을 임의로 고르지 않는다.
4. 작은 화면: 그림은 지정 영역 안에 들어가고 진행/선택/타이머/넘기기 버튼을 덮지 않는다.
5. 실패/중복 입력: 기존 저장 실패·재시도·중복 보상 방지 동작을 유지한다.
