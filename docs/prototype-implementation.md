목적: 작은 현실 행동을 마친 뒤 감정·분기를 기록하고 식물 변화를 확인하는 흐름을 부담 없이 이해하는지 확인한다.

- 캐모마일·수국 두 종류. 원본 저폴리 메시와 머티리얼; Solar Forest의 작은 정원/평면적인 면/부드러운 색을 참고하되 게임 에셋은 복제하지 않는다.

- 감정 건너뛰기 대신 오늘의 기분 입력란(선택, 200 UTF-16 코드 단위)을 표시한다. 선택한 감정을 다시 누르면 해제된다. 감정과 글은 기록하고 성장 보기 버튼으로 함께 확정한다.
- 분기는 오늘의 쉼 방식을 탐색하는 질문이며 MBTI/심리 진단이 아니다. 완료 횟수에 맞춰 4개 문구를 순서대로 사용한다.
- 완료한 미션의 분기 답변만 누적. Quiet(나만의 시간) 우세=캐모마일, Together(연결) 우세=수국. 동률은 마지막 완료 답변 우선.
- 감정·분기 답변은 기록 확정 전 수정 가능, 확정 후 당일 읽기 전용. 이미 끝낸 미션의 기록 대기는 자정에도 유지한다.
- 미션 완료는 감정 기록 화면을 연다. 기록 확정 시 진행과 답변이 함께 반영되고 정적인 성장 팝업을 표시한다. 팝업 확인/뒤로 가기는 메인 복귀만 수행.
- 최종 4단계 이후 꽃 감상. 자동 재시작·5번째 성장 없음.
- 모든 진행/선택은 실행 중 메모리만 유지. Play 종료·앱 재시작 시 씨앗부터 시작한다. PlayerPrefs·파일·클라우드·분석 전송 없음.
- 크림색 배경, 초록색 버튼, 둥근 카드, 감정 얼굴 5개는 사용자 첨부 11590.jpg를 참고한 코드 기반 UI.
- 하단은 홈·정원 / 마음 기록 두 진입점. 마음 기록은 이번 실행에서 완료한 미션의 감정을 최신순으로 보여 준다. 여러 미션·장문 입력·영구 기록은 추가하지 않는다.
- 각 화면 설명문 한 줄 이하. 실제 성장 애니메이션, 영구 기록·진행 저장, 다중 행동 선택, 16종, 새 서버·패키지는 보류.

## 사용자 흐름 / 동작 계약

메인 → 단일 미션 실천 → 완료 → 감정·기분 글·분기 기록 → 성장 팝업 → 메인.

- 감정 미선택: 그대로 기록 확정 가능. None은 0점이 아니라 미기록이다.
- 분기 미선택: 기록하고 성장 보기 버튼 비활성. 메인 복귀·나중 재개 가능.
- 미션 도중 뒤로: 시작 상태 유지, 다시 이어 하기. 실천 완료 후에는 미션 재수행 없이 기록 초안을 이어 간다.
- 같은 날 기록 확정 후: 메인 버튼은 당일 결과만 다시 보여 준다.
- 현지 자정 / 앱 포커스 복귀: 미완료 미션은 새로 연다. 기록 대기인 완료 미션은 먼저 마치고 원래 날짜로 기록한다. 성장과 확정 답변은 유지한다.
- 날짜가 여러 날 지난 경우: 보상·패널티 없음, 한 번의 새 일일 미션만 제공한다.
- 이전 날짜 버튼 입력: 회차 토큰으로 거절한다. 자정 직후 오래된 완료 입력은 새날 미션을 완료시키지 않는다.
- 기기 날짜 역행: 실행 중 이미 본 날짜보다 과거로 돌아가지 않는다. 저장·서버 없는 시연이므로 재시작/기기 시각 조작까지 막는 기능은 아니다.
- 시연 도구: Editor/Development Build에서만 표시. 다음 날로는 앱 내부 시연 날짜만 변경하며 OS 시계를 바꾸지 않는다.
- 초기화: 시연 도구의 확인 화면에서 실행 중 상태만 비운다.

## 마음 기록 변경 — 2026-09-26

### 목표 / 범위 / 계약

- 사용자가 하단 마음 기록 탭에서 지금까지 완료한 날의 감정을 되돌아본다.
- 기존 확정 시점 유지: 감정 선택은 초안이며 미션 완료 시 하루 한 항목을 확정한다. 미완료 초안·빠진 날짜를 기록으로 만들지 않는다.
- 날짜/완료 시각, 얼굴, 감정 이름, 완료한 단일 미션을 최신순 카드로 표시한다. 건너뛴 감정은 감정 미선택이며 긍정/부정 점수로 취급하지 않는다.
- 빈 목록은 빈 상태와 오늘의 미션 진입 버튼. 완료한 날에는 홈·정원으로 복귀한다. 기록 조회는 진행을 변경하지 않는다.
- 반응형: 안전 영역의 가로에 맞춰 카드가 늘어나며 긴 세로 화면은 목록 높이를 확장한다. 초과 내용은 세로 스크롤, Viewport 마스킹, 짧은 목록은 과도한 스크롤 없이 고정한다.
- 재진입 시 최신 항목으로 이동. 반복 조회 시 중복 생성하지 않는다. 현 프로토타입은 4회 완료 상한이므로 최대 4항목이다.
- 영구 저장·내보내기·분석·일기 편집·4회 이후 추가 기록은 범위 밖이다. 모든 감정 기록은 이번 실행에만 존재하며 재시작/시연 초기화 시 사라진다.

### 설계 / 추적 / 검증 계획

Session.Completions의 읽기 전용 목록을 그대로 사용한다. 새 저장소나 도메인 규칙 변경 없음.
Controller는 탐색을 담당하고 MoodHistoryView는 리스트 풀과 빈 상태, MoodHistoryRow는 한 완료 기록의 표시만 담당한다.
기존 씬의 아트·레이아웃을 유지하려면 Apply Mood History UI 메뉴로 한 번 추가한다. 재실행 시 기록 페이지를 중복 생성하지 않는다.

| 탭 이름/기록 탐색 | Controller, SceneBuilder | 실제 버튼 + Play smoke |
| 완료만 기록, 원래 날짜·감정 유지, 저장 없음 | Session.Completions | Edit Mode 기록 계약 테스트 |

민감 데이터: 감정은 메모리에만 사용한다. 네트워크/로그/파일로 사용자 감정을 전송·기록하지 않는다.

사용자의 `표시만 제거` 확인에 따라 미션 수행과 성장 규칙은 유지한다.
감정 화면의 미션 미리보기와 기록 카드의 미션명만 제거하고, 감정 건너뛰기 자리를 선택형 글 입력란으로 교체한다.
메인과 실제 미션 화면의 미션 표시는 유지한다. 기록 화면의 진입 버튼은 오늘 마음 살펴보기/이어하기로 표시하되 기존 경로로 이동한다.

감정(선택)·기분 글(선택)·분기(필수) → 미션 → 완료 시 감정+글 확정 → 마음 기록 최신순 조회.

- 입력은 일반 텍스트, 최대 200 UTF-16 코드 단위(일반 한글 200자). 줄바꿈 허용. 입력창에는 글자 수를 표시한다.
- 화면 이동·미션 전후 돌아보기에서 당일 초안 유지. 미션 완료 후 읽기 전용. 자정에는 미완료 초안만 폐기하고 이전 완료 기록의 글은 유지한다.
- 빈 글도 기존처럼 미션 완료 가능. 공백만 적은 글은 빈 글로 확정, 양끝 공백 제거. 기록에 미션명/임의의 대체 글을 넣지 않는다.
- 긴 글은 입력창 내부에서 스크롤되고, 기록에서는 줄바꿈과 가변 높이 카드로 전문을 확인한다. 사용자 글은 설명문 한 줄 제한 대상이 아니다.

## 미션 진행 상태와 배경 — 2026-09-26 (최신 추가 계약)

## 홈 ↔ 마음 기록 반응형 레이아웃 수정 — 2026-09-27

- 사용자 목표: 탭을 전환해도 헤더·하단 메뉴·주요 버튼이 튀지 않고, 다양한 세로 비율에서 내용이 잘리거나 겹치지 않는다.
- 원인: Controller가 마음 기록에만 `expandHeightToSafeArea`를 켰다. 720×1600에서 홈의 1280 고정 프레임과 기록의 1600 프레임을 교체하면서 공통 헤더/내비게이션까지 움직였다. 기존 검증은 각 화면 내부 적합성만 확인했고 전환 전후 좌표를 비교하지 않았다.
