## 수정한 UI

- 미션·기록의 하단 미선택 버튼이 부모 Sage 테마를 상속하면서 단색으로 그려졌다. 미선택 표면만 기존 정원·설정의 `LeafSet024LitNavigation` 텍스처로 통일했다. 선택 표시와 incoming 제목·일반 버튼은 보존했다.
- 오늘의 기본 미션 카드 표면만 기존 `LeafSet017UI` 잎 배경으로 복원했다. 자식 버튼의 incoming 스타일은 유지했다.
- 디버그 첫 진입 시 화면 밖 입력란에 자동 포커스가 가면서 키보드만 보였다. 잠금 해제 폼을 먼저 스크롤 영역에 노출하고 사용자가 입력란을 누르면 키보드가 열리게 했다. A7의 기억된 인증을 지우지 않았으며 첫 진입 수정은 작은 화면의 합성 UI 검사로 재검증했다.
- 설정으로 전환한 뒤 정원 상태를 갱신하면 코인 아이콘만 다시 나타났다. 정원 표시 상태에 따라 아이콘을 갱신하도록 고쳤다. 실제 A7에서 설정 → Android HOME → 앱 복귀 후 아이콘이 없는 것을 확인했다.
- Unity splash와 Unity logo 표시를 껐다. 최종 release APK의 A7 cold launch 영상에 Unity 로고가 없었다. 엔진 초기화 중 약 4–5초의 짙은 단색 화면은 남으며, 로딩 시간이 0이 된 것은 아니다.

## 남은 시각적 차이: 비교 캡처와 함께 보고, 이번 수정에서 재설계하지 않음

1. 이전 활동 복습·추천, 추가 활동 추천 설정, 이번 주/누적 기록 요약, 경험 종류·경험 목록·경험 상세, 나의 계획, 정원 발견 목록은 구형 나무 배경·왼쪽 제목·강한 프레임/덩굴 버튼·하단 돌아가기 도크를 사용한다. incoming의 연한 표면·중앙 제목·공통 하단 탭과 다르다. 현재 주요 기록 허브와 구형/호환 경로를 구분해 비교했다.
2. 보호된 P/M 미션 시연 선택 화면에도 구형 나무 테마가 남는다.
3. A7의 단독 실습 화면 하단 안전영역에 나무 배경 띠가 남아 파스텔 본문과 이어지지 않는다. 버튼 잘림과는 별개의 표면 차이다. 사용자 확인으로 휴대폰에서는 같은 문제가 없었다. 현재는 A7에서 재현된 문제로 한정하며, 화면 비율·안전영역 처리와의 관련성을 추가 확인해야 한다. 화면 크기 자체가 원인인지는 확정하지 않았다. 이 배경 노출 문제는 아직 수정하지 않았다.

자동 검사에서 기억 잎의 뒤로가기 텍스트 사각형이 부모 버튼보다 2pt 큰 항목이 두 해상도에서 잡혔다. 실제 글자 잘림은 관찰하지 않았다. 스크롤 목록 경계의 부분 표시와 미션별 의도된 파스텔 색은 결함으로 세지 않았다.

### 알림 검증의 구분

제품 앱은 기본 미션 완료 후 오늘 알림을 정상적으로 차단했다. 이번 제품 앱 실행에서 자연 스케줄 알림 → 실제 탭 → 미션 전체 경로를 입증한 것은 아니다.

별도 합성 Android 패키지를 A7에서 실행하여 실제 OS 알림, 실제 PendingIntent 클릭, foreground 방문 및 source_notification_id 연결, QA/build/OS 정보와 이벤트 불변성, 새 프로세스 복구를 검사했다. **produce 29 + restore 16 = 45 checks PASS**.

그 기기에서 생성한 합성 이벤트 13개를 시험 운영자가 외부 HTTPS 서버로 전송하여 **13/13 원문 일치**를 확인했다. 같은 배치를 다시 보내도 최초 수신 시각이 유지됐다. 임시 서버 등록은 철회하고 합성 서버 행의 삭제를 확인했다. 제품 업로더의 자동 전송 증거는 앞의 별도 16건이며, 합성 전송과 혼동하지 않는다.

구형 4-feature 모델의 `events` 테이블에는 이번 A7 경로의 이벤트가 0개였다. 해당 구형 모델의 QA 분류 불변성은 기존 단위/UI 검사로 확인한 범위이며 실제 A7 제품 E2E로 주장하지 않는다. 새 미션 추천은 별도의 `focus_recommendation_*` 이벤트로 위와 같이 확인했다.
