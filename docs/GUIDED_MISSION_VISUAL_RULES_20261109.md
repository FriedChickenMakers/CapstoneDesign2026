# 기본 미션 안내 화면 개선 규칙

P01의 사용자 피드백으로 확정한 기준을 현재 버전 P01–P28에 적용한다. 미션별 의미는 유지하며, 안내 표현만 개선한다. 구현 범위와 검증 증거는 아래 적용 현황의 문서에서 구분한다.

| 항목 | 적용 규칙 | 확인 방법 |
|---|---|---|
| 첫 화면 | 현재 미션 이름과 짧은 목적만 보여준다. 전체 실습 설명을 한 번에 몰아넣지 않는다. | 개요만 읽고 무엇을 하는지 알 수 있는가 |
| 단계 구성 | 기존 실습 흐름 안에서 한 화면에 한 가지 행동을 안내한다. 보통 두 줄 이내, 필요한 선택만 제공한다. | 불필요한 단계나 필수 선택을 늘리지 않았는가 |
| 글자 | 소개에만 제목 30·미션 맥락 16을 표시한다. 소개 이후에는 큰 제목과 반복 미션명을 없애고 핵심 본문 22만 중앙 정렬한다. 실제 줄바꿈 높이를 측정한다. | 짧은 화면과 저장 오류 화면에서 겹치거나 잘리지 않는가 |
| 중앙 그림 | 큰 그림과 중앙 피벗을 유지한다. 화면 높이에 따라 살짝 아래에 배치하고, 본문·버튼 여유를 우선한다. | 최대 280, 제한된 화면 최소 160 설계 단위; 동일 길이 안내 간 위치 유지 |
| 시각적 안내 | 기본 그림의 품질을 높이고 현재 안내와 직접 관련 있는 파동·선·이미지로 행동을 설명한다. 효과는 충분히 분명하게, 실습 중에는 차분하게 표현한다. | 글만 바뀌는 화면이 아닌가; 의미 없는 장식은 없는가 |
| 단계별 효과 | 현재 화면만으로 표시 여부를 결정한다. 연결선의 점은 연결선과 함께 나타난다. 이전·다음 이동 시 다른 단계 효과가 남지 않는다. | 실제 버튼 역행과 최초 방문 화면의 픽셀 비교 |
| 색상 | 미션에 맞는 차분한 테마를 쓰고 주변 배경·아이콘·버튼의 색을 맞춘다. 안내 변화는 완만하게 구분한다. | 색 대비와 일관성, 작은 화면에서도 그림 식별 |
| 조작 | 중앙 그림을 눌러 다음으로 진행한다. 현재 행동을 짧게 안내한다. 종료는 ‘나가기’, 한 단계 복귀는 ‘이전’이다. | 드래그 취소·비활성 화면의 오래된 콜백으로 진행되지 않는가 |
| 도움말 | 이름은 ‘도움말’을 유지한다. 핵심 세 문장을 한 화면에 담고 한 번의 클릭 또는 ‘이전’으로 직전 화면에 복귀한다. | 잘못된 페이지 번호나 실습 초기화 없음 |
| 정보량 | 일반 안내는 한 화면에 담는다. 선택적 돌아보기 입력이 긴 경우만 하단 영역을 스크롤한다. P/M 번호는 개발용 화면에만 표시한다. | 화면 전체 스크롤 없이 중앙 그림/안내/이동 접근 |
| 상태 보존 | 뒤로 이동해도 선택·입력·경과 시간을 유지한다. 도움말/돌아보기에서 시간은 멈춘다. | 저장 실패·재시도·재진입·중복 완료 검사 |
| 범위 | 권장 시간, 필수 여부, 저장 단계/버전, 성장·코인 지급, 과거 기록은 표현 개선과 분리한다. | 기존 미션 검사와 릴리스 컴파일 |

## 검증 원칙

- 320×568, 360×640, 390×844 합성 Unity 화면을 사용한다.
- 코드의 설정값뿐 아니라 실제 그려진 그림과 버튼 경로를 확인한다.
- 기존 P01의 뒤로 이동 강조 잔류·아이콘 드래그 시 초록 사각형 회귀를 유지한다.
- 사용자 저장본과 기기를 덮어쓰지 않는다. 숨긴 별도 Unity 검증으로 물리 마우스를 사용하지 않는다.
- 새 결과를 별도 증거 경로에 남기며 과거 성공 기록으로 이번 변경을 대신하지 않는다.

## 적용 현황

- P01: 큰 인물 그림, 부위별 안내, 한 화면 도움말, 단계별 점/선 및 뒤로 이동 수정 완료.
- P02: 전용 인물/귀 그림과 단계별 소리 표현, 한 화면 도움말 적용 완료. 상세 범위와 이번 34개 그룹 검증 결과는 `P02_SOUND_GUIDE_20261109.md`에 기록한다.
- P01·P02 문구 간소화: 소개 이후 제목/반복 미션명 제거, 짧은 핵심 본문 적용. 전후 문구와 해당 변경의 검증은 `P01_P02_CONCISE_GUIDANCE_20261109.md`에 별도로 기록한다.
- P03–P28: 동일한 제목/본문/배치/한 화면 도움말 규칙, 미션·단계·선택별 그림 적용. `ALL_P_GUIDANCE_20261109.md`에 구현과 이번 검증, `P03_P28_COPY_20261109.md`에 문구 전후와 유지한 분기를 기록한다. M·구형 세션은 기존 화면을 유지한다.
