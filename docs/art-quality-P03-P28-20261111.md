## 공통 구현 및 검증 범위

- 기존 코드 벡터와 안티앨리어싱을 유지한다. 외부 이미지·재질·렌더 텍스처·카메라를 추가하지 않는다.
- `Arrow`의 둥근 끝·화살촉·명암 대비를 통일하며, 더 진한 강조는 행동을 안내하는 선에만 둔다.
- `ConfigureContext(trigger, activity, period)`는 화면 표시용 값만 받는다. 저장·보상 서비스에 접근하지 않으며 미션 변경 시 이전 값을 비운다. 컨트롤러가 기존 세션의 저장된 답/현재 선택을 전달한다.
- 모든 장식은 `OnPopulateMesh`에서 매번 다시 계산한다. 이전 단계의 메시를 누적하지 않고 `raycastTarget=false`를 유지한다.
- 소스 변경에 대해 `git diff --check`를 실행한다. 최종 컴파일·새 렌더·선택/되돌아가기/범위 검사는 전체 P/M 통합 검증에서 별도 확인하며, 이 문서의 점검표 자체가 실행 통과 증거는 아니다.
