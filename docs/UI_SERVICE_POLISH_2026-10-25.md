# UI 일관성과 정원 색감 개선

## 변경 내용

- **설정:** 알림·배경음악을 상태가 보이는 스위치 행으로 바꾸고, 알림 시간은 오른쪽 값과 선택 화살표로 표시한다. 정상 상태를 반복 설명하던 문장을 줄이고 권한·오류 안내는 유지한다. 정원 관련 설정을 같은 그룹에 모은다.
- **Android 기본 화면:** 알림 시간 선택창의 강조색을 정원 녹색으로 통일한다. 시계·숫자 입력 모드의 안내와 버튼을 한국어로 표시하며, 언어 변경은 해당 대화상자에만 적용한다. 기기 언어, 알림 시간 저장·취소 동작, 24시간 표시는 유지한다. 심박 차트의 배경·테두리도 공통 UI 색상에 맞춘다.
- **활동·기록:** 코스, 참여 기록, 경험 기록, 나의 계획의 이동 항목을 공통 목록으로 묶는다. 아이콘 폭과 텍스트 시작선을 통일하고 긴 제목은 줄바꿈한다. 잠긴 활동은 자물쇠와 흐린 글자로 구분한다. 실제 참여 날짜·상태와 저장 실패 안내는 유지한다.
- **홈:** 활동 카드가 어디로 이동하는지 알 수 있도록 화살표와 직접적인 문구를 사용한다. 영양제 수 옆의 상시 조작 설명을 제거하고 상단 패널 높이를 조금 줄인다. 성장 결과 안내와 보기 조작은 유지한다.
- **글꼴:** 기존 공통 제목 46, 소제목·버튼 34, 본문 28, 보조 문구 26의 디자인 단위를 유지한다. 설정 행은 32이며, 여백과 중복 설명을 정리해 밀도를 조절한다. 실제 출력 크기는 Canvas 배율에 따라 달라진다.
- **정원:** 낮 하늘의 파란색과 장면 채도를 조금 올린다. 낮 주광은 1.22에서 1.28로, 색 보정 채도는 0에서 6으로 조정한다. 밤 은하의 기존 가스 밀도에 보라색을 더하며 월드 방향 좌표, 안개, 따뜻한 가로등, 기존 bloom을 유지한다. 추가 노이즈 계산이나 렌더 패스는 넣지 않는다.

## 참고한 설계 원칙

[Material의 목록 지침](https://m1.material.io/components/lists.html)을 참고해 관련 이동 항목의 시작선과 간격을 맞추고, 주 행동 버튼과 일반 탐색 목록을 구분했다. [DWP의 보조 설명 지침](https://design-system.dwp.gov.uk/guidance/hint-text)에 따라 설명을 늘리기보다 항목 이름을 명확하게 만들고, 실제 도움이 필요한 경우에만 짧은 설명을 남겼다. 이 적용이 대상 사용자에게 더 효과적이라는 주장은 사용자 평가 전에는 하지 않는다.

## 검증

- `TabConsistencyCapture.Capture`: 합성 상태 114장, 900×1950·900×1600·1200×800, 텍스트 넘침 0건. 제목·본문·고정 행동 영역 및 컨트롤 겹침 검사 통과.
- `TabConsistencyCapture.CaptureRemaining`: 성장·구매·저장 실패·경험 기록·건강 데이터 상태 등 합성 상태 102장, 같은 세 크기, 텍스트 넘침 0건.
- `GardenSkyValidation`: 낮 은하 표시 유무에 따른 전체 화면 차이 없음, 하늘 이동 불변성, 360도 회전 복귀, 밤 은하 회전 변화 검사 통과. 낮·밤 세로 및 가로 화면을 시각 검토했다.
- `DemoPolishValidation.Capture`: 네 크기(900×1600·900×1950·1200×2000·1200×800)의 성장 미리보기·실패 보존·시간 전환·보기 조작 검사 통과.
- `LocalLoopValidation`: 34 passed, 0 failed. Play fresh/restore 두 단계 통과. 실제 프레임에서 성장 후·재실행 후 홈 배경이 Canvas 전체를 덮는지 캡처 보정 전에 확인한다. 기록 화면의 고정 제목은 스크롤 본문이 아닌 헤더 영역에서 가시성을 검사한다.
- 에디터 캡처의 글자·그래픽 재생성을 보강했다. 홈 캡처는 픽셀이 안정적이라는 조건에 더해 주요 글자가 실제로 렌더됐는지도 검사한다. 정원 배경은 캡처 크기에 맞춰 배치를 갱신한 후 렌더한다. 성장·배치 확정 후 홈 캡처는 이 수정 뒤 재촬영했다. 합성 캡처는 실기기 촬영이나 접근성 서비스 검증으로 소개하지 않는다. 합성 LIVE 건강 상태 역시 Android 알림 권한·시간 선택기 검증을 대신하지 않는다.

- **Android 빌드:** 개발 APK 빌드와 APK 서명 검증 통과. 최종 설치 파일은 비공개 산출물의 `build-native-final/build/capstone-mockup.apk`이며 저장소에 포함하지 않는다.
- **독립 최종 리뷰:** Astra Max가 소스·Editor 이미지·Play 검증을 검토해 PASS를 판정했다. 최종 Android 수정 뒤에도 설치 APK의 소스·해시, A7 실제 화면, 한국어 시간 선택창, 취소 시 설정 보존, 복구 기록을 독립 재검토해 PASS를 판정했다. 리뷰 중 발견한 홈 복귀 캡처의 배경 크기 문제는 캡처 해상도 적용 순서를 수정하고 재촬영한 뒤 해소했다. 초기 독립 리뷰와 구현 담당자의 시각 검토도 별도로 수행했다.

실행 로그, 합성 이미지, 상세 독립 리뷰, 기기 백업과 설정 복구 기록은 Git에서 제외된 `artifacts/ui-service-polish-20261024/`에 보관한다.

## 실기기 검증

- USB 복구 후 A7(Android 10, 1200×2000)에 최종 APK를 데이터 삭제 없이 업데이트했다. 각 업데이트 전 센서 기록·설정·외부 정원 저장을 별도 백업했다. 최종 설치 전후, 앱 실행 전의 기존 파일 58개가 모두 바이트 단위로 같고 설치된 APK 해시도 빌드 산출물과 일치한다.
- 홈·확장 보기·설정 상하단·활동·코스·참여 기록·경험 기록·나의 계획을 실제 화면으로 확인했다. 키보드가 열린 계획 입력 화면에서도 저장·돌아가기 버튼을 사용할 수 있다. 검증 중 기존 기록을 수정하거나 활동 보상을 소비하지 않았다.
- 시간 선택창의 시계 모드와 숫자 입력 모드가 모두 한국어로 표시된다. 숫자 입력 모드에서 취소한 뒤 알림 설정 파일 전체가 동일하며 기기 언어도 바뀌지 않은 것을 확인했다. 실제 알림 시간을 변경하는 확인 동작은 이번 검증에서 실행하지 않았다.
- 건강 기록 화면은 이 기기의 Health Connect 미지원 안내와 설정 복귀를 확인했다. 이는 지원 기기의 실제 심박 데이터 표시 검증을 대신하지 않는다.
- 가상 정원 시간으로 낮 12시·밤 0시와 카메라 회전을 확인하고 실제 시간으로 되돌렸다. 운영체제 시각은 변경하지 않았다. 최종 APK의 낮·밤 스크린샷은 비공개 산출물에 보관한다.
- 최종 앱 프로세스의 보존된 logcat에서 fatal exception, 주요 관리 코드 예외, native crash, ANR 패턴이 발견되지 않았다. 이는 전체 시스템의 과거 장애 이력이나 장시간 성능 보증은 아니다.
- 화면 꺼짐 시간·밝기·밝기 모드를 기록된 원래 값으로 복구하고 기기에서 다시 읽어 일치를 확인했다. 이전 연결 중단 때의 미복구 기록도 재연결 후 복구했다.

기기의 수집·알림 진단은 별도의 비공개 보고서에 기록한다. 개인 기록, 기기 식별자, 연결 주소, 원본 화면과 로그는 저장소에 포함하지 않는다.
