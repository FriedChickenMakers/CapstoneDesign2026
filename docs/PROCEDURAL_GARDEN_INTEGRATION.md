# 절차적 식물의 정원 연결

## 표시와 저장

홈 · 정원과 영양제 성장 미리보기는 `ProceduralPlantView`를 사용한다.
`GardenHomePresenter`는 기존 고정 모델을 숨기고 저장된 Recipe의 정점·법선·색을
실제 섬의 중앙에 표시한다. 제목도 확정된 식물 이름을 따른다.
종류는 생성기의 12종 카탈로그에서 선택되며, 시드는 기존 설치 ID와 고정 개체 ID에서
결정된다. 바람이나 매 프레임 난수로 식물 모양을 재생성하지 않는다.

`GardenState.PlantAppearance`는 기존 schema 1에 추가된 선택적 필드다.
최초 열기에서 기존 성장과 인정 가능한 완료 이력을 반영하고, 다음에는 저장한 기관을
유지하면서 성장한다. 기존 영양제·구매 영수증·미션 완료 기록은 그대로 유지한다.
독립 `PlantGrowthService`를 실행하거나 두 번째 지갑/보상을 만들지 않는다.
새 필드를 이해하지 못하는 이전 빌드도 기존 저장 구조를 읽을 수 있다.

## 기존 데모 성장과의 호환

이번 연결은 시각 디자인을 비교하기 위한 것이므로 기존 영양제 구매 속도를 바꾸지 않는다.

| 기존 성장값 | 화면 단계 | 생성기 내부 단계 (12단계 기준) |
|---|---|---|
| 0 | 씨앗 | 0 |
| 0.1 | 새싹 | 3 |
| 0.2 | 봉오리 | 4 |
| 0.3 이상 | 개화 | 12 |

개화 이후 구매는 이전과 같은 제한된 크기 증가를 유지한다.
독립 생성기의 12회 구매 또는 28/48/56회 미션 성장 프로그램을 앱의 새로운 경제 규칙으로
도입한 것은 아니다. 이 매핑은 `GardenPlantVisuals`에 명시적으로 분리되어 있다.

기록이 없는 기존 개화 식물이 갑자기 새싹으로 돌아가지 않도록, 외형 계산에는
캐모마일 기본 프로필 `[4, 0, 0, 0, 0, 2]`를 사용한다. 이는 **활동 여섯 회를 했다는
기록이 아니라 호환용 외형 prior**이며 별도로 저장한다. 완료·보상 영수증을 만들거나
영양제를 지급하지 않는다. 실제 완료는 명시적인 미션 ID 매핑으로 분류하며,
같은 회차·미션 중복과 하루 3회 상한을 적용한다. 알 수 없는 미션이나 자유 입력의
내용에서 활동 분류를 추측하지 않는다. 확정된 종류와 기존 기관은 새 완료로 재추첨하지 않는다.

## 조명과 미리보기

정점 색 셰이더는 URP 환경광과 실제 태양/달 주광원, 저녁 가로등의 추가 점광원,
그림자를 사용한다. 고정 조명이나 발광으로 밤에도 식물을 밝게 만들지 않는다.
기존 정원 카메라의 HDR·bloom·대비 조정을 그대로 받는다.

성장 미리보기는 분리된 snapshot만 변경한다. 취소하면 원래 메시로 돌아간다.
저장 실패 시 원래 영구 Recipe와 영양제를 유지하며, 미리보기에서 재시도할 수 있다.
정상 저장이 끝난 상태만 다음 실행에서 복원한다.

## 정원과 가까이 보기

홈은 땅·식물·구매한 장식이 함께 보이는 `정원 전체`로 시작한다.
`가까이 보기`는 같은 섬 위의 식물과 작은 테라코타 화분을 확대한다.
두 화면에서 드래그 회전과 `−` / `+` 확대·축소를 사용할 수 있다.
실제 메시 범위로 카메라를 맞춰 전체 보기에서는 섬이, 가까이 보기에서는 식물과
화분이 카드 아래로 잘리지 않도록 한다. 가까이 보기에서 섬 가장자리는 화면 밖으로
나갈 수 있지만 땅과 주변 장식의 렌더러를 숨기지 않는다.

두 보기 모두 같은 땅과 장식, 실제 가로등 광원을 유지한다.
선택한 보기와 확대 정도는 탭을 오가는 동안 유지하며 앱을 다시 시작하면 기본 보기로
돌아간다. 이 값과 화분은 저장 데이터나 구매 항목에 추가하지 않는다.
식물의 배치 크기와 조명은 바뀌지만 Recipe의 정점·색·시드·성장 정책은 그대로다.

낮에는 밝은 잔디와 옅은 흙색, 부드러운 그림자를 사용하고, 밤에는 꽃까지 닿는
차가운 달빛과 주변의 따뜻한 점광원을 함께 사용한다. 별과 은하수는 기존 월드 방향의
하늘 셰이더에 남아 있어 카메라를 돌려도 장면과 일관되게 보인다.

화면 개선 직전 기준은 `3bf8153`, 식물만 남기는 화면을 도입했던 커밋은 `748e741`이다.
후속 부분 롤백은 주변 렌더러 숨김과 식물 보기 기본값만 제거한다.
조명·색상·절차적 식물·화분·확대 기능은 유지하고 변경을 새 커밋으로 기록한다.
비교용 기존 APK·해시·낮/밤 캡처는 private artifacts에 유지하며 Git 이력은 재작성하지 않는다.

## 검증과 되돌리기

- 순수 상태 검사: 기존 저장 마이그레이션, 완료 분류/중복, Recipe 깊은 복사,
  저장 실패 원자성, 새 XML 재열기, 기존 보상/구매 정책 유지.
- Unity 통합 검사: 실제 MockupMain의 생성 메시와 단계별 표시, 재열기,
  미리보기 취소, 저장 실패, 12종의 정원 표시와 낮/밤 조명, 전체 정원 기본값,
  가까이 보기·확대·탭 복귀에서 땅과 주변 렌더러 상태 유지.
- 기기: 기존 데이터를 백업한 뒤 APK를 인플레이스 업데이트하고, 격리된 합성 정원에서
  실제 A7 스크린샷을 촬영한다. 개인 기록과 기기 캡처는 ignored artifacts에만 보관한다.

연결 직전 기준 커밋은 `01afc66`이다. 생성기 최초 도입 `47ac8a2`와 조명/UI 변경은
이전 커밋에 유지하고, 이번 연결은 독립 커밋으로 남긴다. 마음에 들지 않으면
**연결 커밋만 `git revert`**하여 일반 push로 되돌린다. reset/force-push나 전체 브랜치
되감기는 필요하지 않다. 기기 확인 전 APK와 해시는 private artifacts에 별도로 보관한다.
