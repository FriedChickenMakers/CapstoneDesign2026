# P03–P28 안내 문구 간결화 · 2026-11-09

## 범위와 보존 조건

본문은 390단위 화면의 342폭, 22 크기를 기준으로 한 가지 행동을 짧게 안내한다. 개요는 기존 카탈로그를 사용한다. 반복 제목을 UI에서 숨겨도 선택·확인 화면의 본문이 할 일을 설명하도록 구성한다. 이 문서의 전후 비교는 이번 수정 직전의 작업 파일과 비교한 값이며, 원래부터 짧은 문장은 유지했다.

- 수정 대상은 `FocusGuidedPracticeContent.cs`, `FocusBasicSlideContent.cs`의 표시 문구와 새 `ReviewBody` 조회 함수뿐이다.
- P01/P02 기존 함수의 문자열과 별도 Guide를 변경하지 않았다. P07의 호흡·소리 안내는 짧은 전용 배열을 사용하여 P01/P02 수정에 의존하지 않는다.
- 미션명, 카탈로그, `practice`/`notice` 및 모든 단계 키·옵션·RequiredAnswer·분기 조건·버전·시간을 변경하지 않는다. 기존 기록의 제목/본문/값은 다시 쓰지 않는다.
- 필수 입력/선택은 기존대로이며, 선택 사항의 건너뛰기만 허용한다. 도움말은 최대 3개 짧은 문장이고 API 배열 형식을 유지한다. UI는 한 화면에서 합쳐 표시한다.
- 기본/추가 하루 각 1회, 기존 기본 주 6회, 완료 시 성장과 50코인, 독립 감정 기록의 100코인·기억 잎, 자동 사진첩 보관과 다음 성장 미션 새 씨앗 규칙을 변경하지 않는다. 새 부분 성장 정책을 도입하지 않는다.
- 저장 실패·중복 완료·재진입·04시 업무일·재생/대기/타이머 동작은 기존 서비스와 UI가 계속 담당한다.
