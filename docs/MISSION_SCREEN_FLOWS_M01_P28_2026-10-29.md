# M01–M17 · P01–P28 개별 미션 화면 흐름

작성일: 2026-10-29. 기준: [`main`의 `MindfulnessContent.cs`](../Assets/Scripts/Runtime/MindfulnessContent.cs), 커밋 `26b6063`.

이 문서는 **기존 자유 미션 `M01`–`M17` 17개와 기존 코스 미션 `P01`–`P28` 28개**의 목표 화면 설계다. [2주 MVP 미션 UI 문서](MISSION_UI_BENCHMARK_AND_FIGMA_FLOW_2026-10-28.md)가 다루는 `MBCT2W01`–`MBCT2W12` 및 현재 2·4·8주 코스와는 별도 범위다. 아래 문구와 화면 순서는 구현·검증 완료 상태를 뜻하지 않는다.

## 화면 공통 규칙

- 표의 `①`, `②` 등 **번호 하나가 실제 앱/Figma 프레임 하나**다. 첫 화면은 미션 개요와 `[시작]`, 중간 화면은 그 순간의 행동 하나와 주 버튼 하나를 보여준다. 선택지나 직접 입력이 필요한 경우에만 추가한다.
- 모든 행의 마지막 `완료 화면`은 **신규 완료** 시 `미션 완료! · 영양제 +{실제 지급량}`과 `[정원으로]`를 보여준다. **복습**이면 `복습 완료 · 추가 보상 없음`을 보여준다. 지급량은 저장된 보상 결과를 사용하고 화면에 고정하지 않는다.
- 권장 시간은 실습 화면에 표시할 수 있지만 타이머 종료만으로 완료시키지 않는다. 코스 실습의 선택적 회고에는 `없음`, `잘 모르겠음`, `건너뛰기`를 허용한다.
- 이전 단계, 잠시 쉬기, 나중에 이어하기가 필요한 화면은 현재 단계·선택·입력 초안을 보존한다. 실제 행동을 앱이 감지하지 못하는 미션은 사용자 확인 버튼으로 완료한다.
- 음원 A–E가 없어도 글 안내만으로 수행 가능한 흐름을 우선한다. 단, P24의 대체 듣기 경로에는 **앱이 제공할 짧은 이야기 음성 제작이 필요**하다.

## 제작 및 검토 메모

| 항목 | 후속 작업 |
| --- | --- |
| 프레임 이름 | `M01-01 개요`, `M01-02 수행`, `M01-03 완료`처럼 미션 ID와 화면 번호를 함께 사용한다. P19처럼 갈라지는 경로에는 `산`·`소리 대체`를 덧붙인다. |
| 기존 Figma 안내 프레임 | 한 장에 여러 안내를 모은 프레임은 이 문서의 화면별 흐름으로 교체한다. 화면 전환과 버튼 연결도 확인한다. |
