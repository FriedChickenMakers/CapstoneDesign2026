# 정원 구름과 밤 조명 참고

2026-10-12 기준. 구름 사진을 앱 텍스처로 복제하지 않고 형태와 조명 설계에만 참고했다. 앱의 밀도 텍스처는 코드가 생성하는 원본 절차적 데이터다.

## 공개 참고 자료

- [미국 기상청 구름 분류](https://www.weather.gov/lmk/cloud_classification): 적운의 둥근 상단·비교적 평평한 하단, 층적운의 두꺼운 부분과 얇은 부분, 권운의 가는 형태를 구분한다. [적운 사진](https://www.weather.gov/images/lmk/soo/cumulus.jpg), [층적운 사진](https://www.weather.gov/images/lmk/soo/stratocumulus.jpg), [노을 사진](https://www.weather.gov/images/lmk/soo/Sunset23Nov2005_med.jpg)을 함께 참조한다.
- [미국 기상청 구름 사진표](https://www.weather.gov/media/bis/CloudChart.pdf): 하나의 동일한 타원을 반복하는 대신 구름 종류별 높이·두께·덩어리 분포를 분리하는 기준이다.
- [Unity Particle System Renderer](https://docs.unity3d.com/6000.3/Documentation/Manual/PartSysRendererModule.html): 정원에서는 카메라를 향한 빌보드와 거리 정렬을 사용한다. 구름은 불투명한 섬 뒤에서 깊이 검사를 받는다.

공식 문서의 형태 설명과 공개 사진 링크를 확인했다. 이번 웹 도구는 해당 사진의 픽셀을 전달하지 않았으므로, 원본 사진에 대한 Vision 검증을 수행했다고 주장하지 않는다. 앱에서 생성한 실제 렌더는 별도로 Vision 검토한다.

## 적용

구름 윤곽은 비대칭으로 배치한 여섯 덩어리의 거리장과 밀도 침식으로 만든다. 덩어리 사이를 부드럽게 결합해 내부 음영에 직선 경계가 생기지 않도록 한다. 전 영역을 흐린 Gaussian 타원으로 만들던 방식 대신 가장자리만 좁게 부드럽게 처리하고, 내부는 위·아래 밝기와 광원 방향, 서로 다른 크기의 밀도 변화로 두께를 표현한다. 먼 층은 얇고 더 잘 끊어지는 형태다. 형태는 사진 같은 체적 시뮬레이션이 아니라 저폴리 정원에 맞춘 표현이다.

총 24개의 입자를 세 높이의 바람 흐름에 분산한다. 입자마다 폭·높이·방향·윤곽·속도가 다르며, 화면 밖에서 감기도록 이동 범위를 확보한다. 섬 중앙을 피하고 모두 섬보다 뒤에 둔다. 낮·노을·밤은 하늘, 구름, 방향광, 주변광이 같은 시각을 사용한다. 밤은 선형 색 출력에 맞춰 하늘을 어둡게 하고 달빛과 주변광을 낮춘다.

모바일 비용 상한은 입자 24개, 입자당 빌보드 1장, 생성 시 한 번 만드는 64×64 RGBA32 밀도 텍스처(16 KiB), 프래그먼트당 텍스처 읽기 3회다. 반복적 ray marching, 입자별 라이트, 구름 그림자 맵은 사용하지 않는다. 정원 갱신 주기는 기존 10 Hz를 유지한다. 실제 기기 프레임 시간은 별도 측정 없이는 보장하지 않는다.

정원 시간 설정의 변경 이벤트는 재료와 조명을 즉시 갱신하고 다음 `LateUpdate`에 렌더하도록 예약한다. Canvas 콜백에서 렌더를 재진입하지 않는다. 이 시각 설정은 건강 기록·활동 날짜·알림 시간에 사용하지 않는다.

구름의 RGB와 알파는 서로 다른 혼합 계수를 쓴다. RGB용 `SrcAlpha`를 알파에도 쓰면 불투명한 하늘의 알파가 낮아져, 정원을 UI `RawImage`에 표시할 때 밝은 UI 배경이 밤 구름에 비쳐 보인다. 별도 알파 혼합 `One, OneMinusSrcAlpha`로 하늘의 불투명도를 유지하고 렌더 텍스처 전체의 알파를 회귀 검사한다.

## 검증 범위

`GardenEvolutionCapture.CaptureAtmosphere`를 Unity Editor Vulkan에서 실행했다. 최종 결과는 무시된 `artifacts/evolution-20261012/garden/atmosphere-final-pass/`의 13장과 `validation.txt`다. 실제 생성된 낮·노을·밤 및 900×1950 홈 화면을 Vision으로 검토했으며, 섬 중앙 가림과 구름의 직선 음영 경계가 없고 밤 구름의 UI 합성 과노출이 해소됨을 확인했다. 밝은 꽃·잔디·섬 윤곽은 밤에도 구분되며 어두운 장식 세부는 낮보다 덜 보이는 야간 표현이다.

- 밤/낮 렌더 평균 RGB 밝기: 32.71 / 188.64(약 17.3%). 화면 전체 합성 전 정원 렌더 기준이며 측광·기기 밝기 값이 아니다.
- 구름이 있는 정원 렌더 텍스처의 모든 픽셀 알파가 250/255 이상을 유지한다.
- 60초 후 24개 중 24개 입자가 이동한다. 수·속도·텍스처 상한은 코드로 제한한다.
- 실제 방향광 그림자 켜기/끄기 비교에서 정원 픽셀 71,440개가 유의하게 어두워졌다.
- 모든 시각에서 구름 재료의 낮 밝기 값과 정원 조명 값이 일치한다. shader 오류·SRP 재귀 렌더 오류는 없다.

이 검증은 합성 상태를 쓰는 Editor 렌더다. Android 기기 설치·GPU 프레임 시간·실제 배터리 소모를 검증한 결과로 확대하지 않는다. 원본 스크린샷은 무시된 `artifacts/`에만 보관한다.
