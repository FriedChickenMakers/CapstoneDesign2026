# P02 주변 소리 만나기 화면 개선

## 목표와 보존할 계약

사용자가 짧은 문장과 그에 대응하는 그림으로 소리 관찰을 따라가도록 한다. P01에서 확정한 규칙은 `GUIDED_MISSION_VISUAL_RULES_20261109.md`를 따른다.

후속 문구 간소화로 소개 이후에는 제목·반복 미션명을 없애고 핵심 본문만 표시한다. 현재 문구 전후 표와 해당 검증 결과는 `P01_P02_CONCISE_GUIDANCE_20261109.md`를 참조한다.

미션 이름은 **주변 소리 만나기**로 유지한다. 현재 버전의 저장 단계 `practice`/`notice`, 권장 60초, 자유로운 실습 종료, 선택적 돌아보기, 완료 성장 및 50코인 경로를 바꾸지 않는다. 준비 단계에 새 선택지를 만들지 않는다. 과거 버전의 세션과 P07이 참조하는 공통 안내 문구도 보존한다. 마이크·녹음·소리 재생·소리 맞히기·측정 기능을 추가하지 않는다.

## 화면별 설계

| 화면 | 짧은 안내 | 시각적 설명 | 사용자 동작 |
|---|---|---|---|
| 개요 | 주변에서 들리는 소리에 잠시 귀 기울이는 실습 | 귀와 표정이 잘 보이는 인물, 간단한 소리 파동 | 그림으로 준비 시작 |
| 준비 | 편하게 앉기, 눈은 뜨거나 감아도 됨 | 동일 인물, 편안한 공간/자세 | 그림으로 첫 안내 |
| 안내 1 | 가까이 또는 멀리 들리는 소리 하나 | 귀 쪽 한쪽에만 소리 파동 | 다음 안내 |
| 안내 2 | 크기·높낮이·시작과 끝 | 오른쪽 세로 3개 파형, 위로 갈수록 굵고 진폭이 큼 | 다음 안내 |
| 안내 3 | 다른 생각을 알아차리고 지금 소리로 복귀 | 생각 구름과 귀로 향하는 화살표 | 기존 실습 시작 명령 |
| 실습 | 이름이나 원인을 맞히지 않고 편한 만큼 듣기 | 효과를 줄인 차분한 인물/귀 | 기존 일시 정지·선택 돌아보기·실습 마치기 |
| 돌아보기 | 기억에 남은 소리; 선택/글은 생략 가능 | 동일 인물과 메모 | 기존 소리 종류 선택/선택 입력 |
| 도움말 | 이름 맞히기 불필요 / 조용하면 기다리기 / 생각이 들면 소리로 | 책과 인물 | 한 번 클릭 또는 이전으로 직전 화면 |
| 완료 | 기존 완료·보상 정보 | 동일 인물의 메모 그림 | 기존 오늘의 미션·정원·기록 이동 |

## 구현 책임

- `P02SoundGuide`: 현재 버전 P02 전용 제목/본문. 공통 정책이나 P07 공유 문구를 변경하지 않는다.
- `WeekOneQuestDemo.P02Sound`: 기존 안내 단계와 그림 연결, 차분한 파랑/청록 테마, 중앙 클릭 영역 생성.
- `P02SoundIllustration`: 코드로 그리는 비입력 벡터. 현재 단계로만 효과를 결정하며 시간·센서·저장에 의존하지 않는다. 인물 중심은 고정한다.
- `WeekOneQuestDemo.GuidedFocusPractice`: P01과 P02에 기존 측정형 글자/아이콘 배치 적용, P02 도움말 한 화면 연결. P03 이후는 유지한다.
- `WeekOneQuestDemo.FocusPractice`: 현재 버전 P02 완료 화면에 같은 그림 사용.

P02는 돌아보기의 88 설계 단위 입력란을 작은 화면에서도 온전히 볼 수 있도록 하단 최소 여유를 100으로 지정한다. P01의 기존 86과 다른 미션 배치는 유지한다. 하단 입력 영역만 스크롤하며 중앙 그림은 화면에 남는다.

## 검증 계획

기존 GuidedFocusValidation에 세 화면 크기의 P02 실제 버튼 흐름·렌더 비교를 추가한다. 단계별 그림 차이, 뒤로 이동 시 최초 그림 복원, 큰 글자/그림과 하단 동작 분리, 드래그 취소, 한 화면 도움말, 시간/초안 보존, 선택적 입력 접근, 저장 실패·재시도·기존 완료 보상 검사를 실행한다. 기존 P01과 P03–P07, 과거 세션 검사를 유지하고 DailyMissionValidation으로 일반 미션 회귀와 릴리스 컴파일을 확인한다. 새 합성 캡처를 직접 검토한다.

검증은 별도 합성 저장소와 숨긴 Unity에서 수행한다. 원본 편집기, 사용자 데이터, 마우스는 건드리지 않는다. Android 실기기 성능은 이 검증에 포함하지 않는다. 커밋·푸시하지 않는다.

## 파형 정리와 귀 표현 수정

사용자의 실제 화면 피드백을 반영했다. 첫 안내는 오른쪽 파동을 제거해 귀 쪽 파동만 남긴다. 두 번째 안내는 오른쪽에 동일 폭의 파형 세 개를 세로로 정렬하며, 위/가운데/아래의 선 두께는 4/2.8/1.8, 진폭은 14/9/5 설계 단위다. 파형은 정적인 예시이며 녹음·측정과 관계없다.

귀는 외곽 크기를 줄이고, 짙은 내부 색면과 복잡한 굴곡을 제거해 연한 곡선 하나로 단순화했다. 돌아오는 화살표 끝도 줄어든 귀 위치에 맞췄다. 글·화면 배치·조작·저장·보상은 변경하지 않았다. 기존 안내 UI 검사를 재실행하고 새 캡처에서 실제 모양을 검토한다.
