# 추가 미션 전체 안내 개선

## 범위와 유지할 계약

2026-11-11 사용자 요청으로 M01에서 정립한 규칙을 M02–M17에 확장한다. M01의 커튼·조명 분기는 유지한다. 현재 v5와 동일한 단계 구조를 사용하는 v4의 안내 표현을 개선하며, v2·v3의 저장된 실습은 기존 화면을 사용한다. 이 문서는 이번 변경의 기획·구현 범위이며, 아래 검사 항목의 완료 여부는 실제 실행 결과로 별도 기록한다.

- 소개에만 미션 제목을 표시한다. 이후에는 중앙 정렬한 짧은 본문으로 한 행동만 안내한다.
- 소개 이후 안내 본문은 보통 두 줄, 도움말은 한 화면의 핵심 세 문장으로 제한한다. 개발용 화면 외에는 P/M 번호를 노출하지 않는다.
- 큰 중앙 그림을 눌러 진행한다. 그림은 미션별 장면과 현재 단계의 동작·강조를 보여준다. 같은 미션은 안내와 조작에 필요한 공통 공간을 확보해 그림 중심이 단계마다 흔들리지 않게 한다. 이전 화면으로 돌아오면 해당 단계의 그림만 다시 그린다.
- 나가기는 저장 후 재개, 이전은 직전 단계, 미션 넘기기는 기존 별도 확인을 거쳐 무보상 미완료 종료다. 도움말과 검토 화면에서 타이머를 진행시키지 않는다.
- 기존 단계 키·카탈로그 버전·선택지·필수 입력·권장 시간·걸음 검증·완료·성장·코인·일일 한도를 바꾸지 않는다. 추가 안내를 새 저장 단계나 필수 설문으로 만들지 않는다.
- 입력·그리기·걸음 확인 등 필요한 조작은 유지한다. 후속 사용자 확인에 따라 M 안내 화면과 답변 영역 모두 스크롤 없이 구성한다. 한 화면에 길게 쌓는 대신 실제 글자 높이를 측정해 내용별로 페이지를 나눈다. 긴 저장 답변도 중앙 아이콘으로 다음 내용을 확인하며 원문을 생략하거나 자르지 않는다.

## 미션별 안내와 그림

표의 화살표는 기존 저장 단계 순서다. 각 단계는 별도 화면이며, 마지막 아이콘 확인은 기존 완료 서비스로 이어진다. M02–M17은 기존 34개 단계로 진행한다.

## 표현과 상태의 분리

`FocusAdditionalSlideContent`는 소개·단계별 짧은 문구·도움말만 제공한다. 미션 정의를 복제하거나 수정하지 않는다. M02–M17의 기존 34개 단계 키를 모두 명시하고, 알 수 없는 코드나 단계는 임의 안내를 만들지 않고 빈 문자열을 반환한다.

M10은 같은 `plan` 키라도 v4가 필수 자유 입력, v5가 행동·시간대 선택이다. 현재 카탈로그의 `Kind`에 따라 맞는 UI와 문구를 사용하며 과거 답변을 새 계획 형식으로 해석하지 않는다. v5의 시간대는 알림 시각과 별개다. M15는 화면의 장식 경로를 실제 위치 추적이나 측정 결과처럼 표시하지 않는다. M11의 예시 그림과 사용자의 실제 획을 구분한다.

M10의 행동·시간대·선택적 글은 표시 페이지로만 분리한다. 각 페이지 이동 전에 기존 `SaveFocusPlan` 경로로 현재 선택을 보존하고, 실패하면 그 페이지에 남는다. M07·M10의 긴 확인 문구는 실제 높이에 맞게 나누되 저장 값은 바꾸지 않는다. 페이지 넘기기 자체는 단계 완료·보상으로 처리하지 않는다.

선택·입력·그림·경과 시간은 기존 세션 저장 흐름을 사용한다. 그림과 도움말은 표현 상태이므로 완료 보상이나 새 저장 필드를 만들지 않는다. 화면 root·세션·revision·확인 창 상태로 오래된 콜백을 차단하고, 실패한 저장은 원래 화면에서 재시도한다.

## 구현 책임과 보존한 기능

- `WeekOneQuestDemo.BasicFocusSlides`의 기존 슬라이드·이전·저장 흐름을 M02–M17에서도 재사용한다. P의 저장 실패 중 읽기 전용 도움말 접근 동작은 유지한다.
- `WeekOneQuestDemo.AdditionalFocusSlides`는 계획의 표시 페이지, 그림 입력/확인, 걸음 상태와 긴 답변의 확인 페이지를 제공한다. M11 확인 화면의 중앙 그림은 실제 저장된 획이며 입력 캔버스 비율을 유지한다.
- `AdditionalMissionIllustration`은 각 미션의 장면과 현재 단계 효과만 그린다. M17은 참고용 원만 천천히 움직이고, 동작 줄이기 설정에서는 멈춘다. 새로운 텍스처·재질·카메라는 추가하지 않는다.
- `FocusGuidedSlideLayout`은 실제 소개 글 높이와 해당 미션의 조작 공간을 예약해 정상 단계의 그림 중심과 크기를 유지한다. 짧은 화면의 낙서는 그리기 공간을 확보하도록 그림을 축소하며, 저장 오류 안내가 나타나면 읽기·재시도 공간을 우선한다.
- `WeekOneQuestDemo.FocusAdjustments`는 미션 넘기기·시간 단축의 기존 서비스 호출을 유지하며, 취소한 확인 창의 오래된 확인·취소 동작을 차단한다. 추가 미션 넘기기 안내에는 보상과 일일 횟수 미소모를 명시한다.
- `AdditionalFocusSlidesValidation`은 실제 UI raycast·합성 GPU 렌더·저장 실패를 검증한다. 기존 관련 검사도 새 중앙 아이콘 경로로 연결하되 완료·보상·입력 필수 조건은 그대로 검사한다.

## 이번 검증

아래 항목을 별도 합성 Unity 프로젝트의 새 실행으로 확인했다. 과거 M01/P 검사 수치를 이번 변경의 결과로 재사용하지 않았다.

- M01–M17 현재/지원 버전의 소개·전체 단계·이전·한 화면 도움말 실제 경로.
- 320×568, 360×640, 390×844에서 제목·본문·그림·입력·타이머·하단 조작의 겹침과 잘림, 스크롤 없는 접근, 단계별 그림 중심 유지.
- 모든 M 고유 그림 및 단계 효과, 선택 후 이전에서 강조 잔류 없음, 드래그 취소.
- M07/v4 M10 필수 입력, v5 M10 계획 선택·수정, 긴 확인 문구의 전체 원문 보존·페이지 이동, M11 그림·재검토, M15 걸음 확인 보존.
- 도움말·이전·나가기·재진입의 선택·입력·경과 보존, 넘기기 확인/취소.
- 저장 실패·재시도·중복 콜백·완료 1회·성장 1회·50코인 1회, 일일 한도.
- 기존 P·M01·구버전 회귀, Unity 컴파일과 비개발 Player 컴파일.
- 별도 합성 저장소·숨긴 Unity GPU 렌더 사용. 사용자 저장본·원본 Unity 마우스·연결 기기를 조작하지 않는다.
