# 중간발표 데모 품질 개선 — 2026-10-15

현재 구현의 활동·기록·성장 흐름을 명확하게 다듬었다. 아래 7개 항목을 구현하고 합성 상태의 Editor·Play 검증과 Android 빌드를 수행했다. 새 보상 체계나 임상 개입은 추가하지 않았다.

## 반영한 동작

| 항목 | 변경 후 동작 |
|---|---|
| 활동 카드 | 실제 저장된 선택·진행·일시정지 세션을 우선 표시한다. 카드 제목과 이동 버튼이 같은 활동을 가리키며, 진행 중인 활동을 새 추천으로 잘못 소개하지 않는다. |
| 참여 기록 | 목록에 종료 시각과 상태를 함께 표시한다. 모든 완료 기록에 보상이 지급된 것처럼 보이던 문구를 제거하고, 완료·참여 종료 상태를 구분한다. |
| 8주 코스 탐색 | 앱 실행 후 첫 진입은 현재 추천 활동의 주차로 열린다. 이후 사용자가 직접 고른 주차는 같은 실행 동안 유지한다. |
| 성장 한계·저장 | 기존 렌더링 상한에 도달하면 더 이상 영양제를 차감하지 않는다. 마지막 유효 성장은 상한까지 반영하며, 이미 상한을 넘는 구버전 저장값은 낮추지 않는다. 동일 구매 요청 재시도로 중복 차감하지 않는다. |
| 성장 미리보기·확정 | 화분·식물을 중심으로 ‘현재’와 ‘성장 후’를 같은 카메라 위치·회전·배율로 비교한다. 확정 버튼에 영양제 10개 사용을 명시하고, 성공 후 사용량을 안내한다. 미리보기·취소는 저장하지 않으며, 저장 실패 시 기존 성장·잔액을 유지한다. 구매 불가 버튼은 중립색으로 구분한다. |
| 정원의 시간 | 설정의 건강 기록 아래에 배치한다. 기존 다이얼과 ‘실제 시간으로’를 유지하고 ‘낮 12시 보기’·‘밤 0시 보기’를 추가했다. 바로가기는 전체 정원·기본 회전·줌으로 되돌린 뒤 홈을 연다. |
| 홈 보기 조작 | 가까이 보기·전체 정원·확대/축소는 ‘보기 +’에서 펼친다. 기본 상태는 접혀 있어 정원을 가리는 면적을 줄인다. 펼친 조작 버튼의 크기는 유지한다. |

성장 상한은 새로운 식물학적 성숙 판정이 아니라 기존 표시 크기의 한계다. `MaxVisualGrowth`는 약 `1.02`이며 기존 최대 배율을 유지한다. 성장 가능 여부, 미리보기, 실제 구매가 같은 계산을 사용한다.

정원 시간 변경은 `GardenVisualClock`의 실행 중 표시값만 바꾼다. 시스템 날짜·활동 날짜·알림은 바꾸지 않으며 앱을 다시 실행하면 실제 시간으로 돌아간다.

실행 로그와 합성 캡처는 무시된 로컬 `artifacts/`에 보관한다. MBCT 및 Unity 로그는 `artifacts/demo-polish-20261015/`에 있다. Editor 합성 화면을 실제 기기 촬영본이나 실제 건강 데이터로 소개하지 않는다.

화면 검증 진입점은 `DemoPolishValidation.Capture`와 `DemoPolishValidation.CaptureActivities`다. `CAPSTONE_ARTIFACTS`에 비공개 출력 디렉터리를 지정하고, `scripts/unity-run.sh`에서 그래픽 장치가 있는 Editor로 실행한다. 캡처는 메모리 저장소와 합성 시계를 사용한다. Editor는 런타임의 `OnEnable`을 호출하지 않으므로 이벤트 등록과 시각 시간 갱신을 명시한다. 해상도 변경 후 목록 캡처는 최상단을 지정하며, 실제 첫 진입 위치는 별도의 Play 검사로 검증했다. 최종 기기 표시·터치·Android 생명주기는 별도 확인 대상이다.

## 이번 범위 밖

앱의 임상 효과, 대상 사용자 사용성·지속성, L-system 대비 형태 타당성·다양성·선호, 알림 개인화의 비교 효과는 아직 검증하지 않았다. 조사한 평가 계획을 실험 결과로 소개하지 않는다. 새로운 L-system 비교 구현이나 사용자 연구 기능도 이번 UI 개선에 포함되지 않는다.
