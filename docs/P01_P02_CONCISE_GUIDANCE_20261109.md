# P01·P02 안내 문구 간소화

## 요청과 적용 범위

제목·반복 미션명·설명이 함께 보여 글을 따라가기 어렵다는 피드백을 반영한다. **미션 소개의 제목·본문은 그대로** 두고, 그 이후 화면은 큰 제목과 상단 반복 미션명을 생성하지 않는다. 본문 22의 중앙 정렬만 남기고, 비어 있는 제목 행 없이 본문을 126 설계 단위 위치에 놓는다. 기존 아이콘 중심/크기·그림·조작은 유지한다. 단계 표시, 나가기/이전/도움말, 선택/건너뛰기 힌트는 남긴다.

현재 버전의 P01·P02 안내만 대상이다. 완료 화면의 보상 안내, 과거 버전 세션, P03 이후와 추가 미션, 저장 단계·성장·재화·권장 시간은 변경하지 않는다. 단순화를 위해 별도 페이지나 필수 선택을 만들지 않는다.

## 구현과 검증

P01/P02 전용 Guide가 문구를 소유한다. GuidedFocusPractice는 소개 여부에 따라 제목·맥락을 생성하고, FocusGuidedSlideLayout은 제목 없는 본문도 기존 큰 그림 배치로 다룬다. 소개 이외의 `Title` API는 빈 문자열이다. 도메인/저장 코드 변경은 없다.

기존 GuidedFocusValidation의 P01/P02 흐름에 소개 화면 보존과 소개 이후 제목·반복 미션명 오브젝트 부재를 확인한다. 본문 가시성/위치, 작은 화면 및 저장 실패 중 배치, 선택/역행/도움말/선택적 입력/저장·보상 회귀를 합성 Unity에서 재실행한다. 일반 미션 검사와 릴리스 컴파일도 실행하며, 실제 캡처를 검토한다. 원본 저장소·기기·물리 마우스는 사용하지 않는다. 커밋·푸시하지 않는다.
