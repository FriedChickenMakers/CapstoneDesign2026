# P01–P28 목적·단계·허용범위 재매핑 — content v5, 2026-11-09

2026-11-09 통합한 content v5의 **코드와 기존 근거 문서 연결을 완료한 표**다. 새 문헌 조사, 전문가 심사, 임상 효과·실습량 검증을 수행한 보고서가 아니다. 2026-11-10 QA 게시에서는 근거 문서 링크와 Git 상태 설명만 갱신했다. 상담사 추가 문의는 사용자가 이번 개발의 선행 작업에서 제외했다.

코드의 `Purpose`는 개발팀이 정한 좁은 활동 목표다. 표의 ‘보존’도 제품 설계 계약이며, 전문가가 승인한 임상 최소 절차를 뜻하지 않는다. 현재 30/45/60/120초는 **앱 기본 추천값**이다. 공식 MBCT 권장량·임상적 최소 시간으로 표현하지 않는다.

## 확인한 실행 경로와 공통 규칙

- 카탈로그: [FocusMissionCatalog.cs](../Assets/Scripts/Runtime/FocusMissionCatalog.cs)의 신규 `Version=5`, 보존된 `AllV4`, [TextureHistory](../Assets/Scripts/Runtime/FocusMissionCatalog.TextureHistory.cs)의 v3와 목적 메타데이터.
- 실제 화면: P01–P07은 [GuidedPracticeContent](../Assets/Scripts/Runtime/FocusGuidedPracticeContent.cs)·[GuidedFocusPractice](../Assets/Scripts/Runtime/WeekOneQuestDemo.GuidedFocusPractice.cs), 나머지는 [BasicSlideContent](../Assets/Scripts/Runtime/FocusBasicSlideContent.cs)·[BasicFocusSlides](../Assets/Scripts/Runtime/WeekOneQuestDemo.BasicFocusSlides.cs). 카탈로그만 보고 화면에 없는 문장을 있다고 간주하지 않았다.
- 시간·기록: [LocalGardenState.cs](../Assets/Scripts/Runtime/LocalGardenState.cs)의 `StartFocusPracticeStep`, `ShortenFocusStep`, `ShortenGuidedFocusPractice`, `ConfirmFocusStep`, `EndFocusParticipation`, `BeginFocusAlternative`와 [FocusAdjustments UI](../Assets/Scripts/Runtime/WeekOneQuestDemo.FocusAdjustments.cs).
- 표의 초수는 **각 단계별 기본값**이다. 시간이 있는 실제 실습의 카운트다운을 시작한 뒤 `너무 길어요`를 사용할 수 있다. 팝업 중 일시정지하고 ‘여기까지 하기’는 현재 구간만 마친다. 남은 단계는 유지한다. ‘취소’는 재개하며 단축 피드백을 만들지 않는다.
- 다음 추천에는 같은 콘텐츠 버전·미션·단계의 **확정된 too_long 실제 시간**만 사용한다. 다른 미션, 준비 화면, 팝업 취소, 보통 미루기를 같은 피드백으로 해석하지 않는다. 추천 시간과 실제 경과 시간은 별도 저장한다.
- P01–P07은 저장상 `practice → notice` 두 단계다. 자세·대상 선택·복귀 안내는 guided 화면에 포함되고, 관찰 답변은 모두 선택이다. 나머지 P 중 필수 답변은 v5 P25 `speak`다. ‘필수 보존’은 안내·분기를 없애지 않는다는 의미이지 모든 감정/서술 답변을 강제한다는 의미가 아니다.
- 미루면 기본 코스의 현재 회차를 유지한다. P19/P26의 다른 목적 대안은 별도 P02 지원 활동으로 기록하며 하루 추가 활동 1회에 포함한다. 미완료는 코인/부분 성장 없이 실제 수행 기록만 남긴다. 정상 완료만 현재 성장·50코인 규칙을 따른다.

## 이번에 마친 것과 별도로 남은 것

**완료:** 28개 목적을 실제 카탈로그·화면·저장 단계와 대조하고 기본 시간, 현재 선택지, 필수 답변, 다른 목적 대안, v4 호환과 기존 문서 근거를 연결했다. 위 단계·초수 목록은 현재 C# 카탈로그를 직접 실행해 추출한 값과 대조했다. 재매핑 작업 자체는 문서만 작성했다. 이 과정에서 확인한 P21/P28 문구 누락은 별도 승인된 후속 개발에서 v5에 한정해 보완했다.

**별도 미확인:** 개별 초수/단축량의 임상 타당성, 프로그램 전체 fidelity·효과, D1의 전문가 질문 답변, P19 태도 안내의 충분성, P26 원 프로그램 계열 연결은 기존 자료만으로 확정하지 않았다. P21/P28의 관찰 기준점 누락은 v5 문구 보완으로 반영됐지만 그 안내의 임상적 충분성까지 승인된 것은 아니다. 두 미션×v4/v5×두 해상도의 실제 선택·실습 화면과 P19/P26→P02의 추가 활동 표시·진도 분리는 최종 Unity 12개 회귀(256 assertions)에서 확인했다. 이는 코드·표시 검증이며 임상 심사와 구분한다.

검증 근거는 [QA 배포 준비 기록](QA_RELEASE_READINESS_20261109.md)의 host 39/39, 목적/허용범위 도메인 회귀, 원본 저장 호환, Unity 목적 문구 검사 및 7종 통합 UI PASS다. 이 가운데 7종 통합 UI는 P21/P28 마지막 문구 보완 전 동결 결과다. 보완 후 최종 12개 회귀는 `artifacts/qa-release-20261109/unity/qa-regression-final12/qa-integration-validation/report.json`의 12/12 PASS·256 assertions로 별도 확인했다. 최종 `.2`/2026110903 APK의 A7/API29 업데이트·기존 저장/등록 보존 검사도 통과했지만, 해당 단말 검사를 28개 콘텐츠의 학습 효과 평가로 해석하지 않는다. 해당 검사는 기능·기록·표시를 확인하며 사용자가 실제로 목표를 학습했는지 또는 증상이 개선됐는지는 측정하지 않는다.
