# 2026-10-12 구현 계획

사용자 요청 전체를 완료 기준으로 유지한다. 아래 체크는 구현과 해당 범위의 검증이 끝났을 때만 완료한다. 개인 데이터·기기 주소·원본 캡처는 추적하지 않고 비공개 `artifacts/`에 보관한다.

## 작업 유지 및 자원 조건

- Quota 잔여가 5% 미만으로 확인되면 기기 설정을 복구하고 진행 상태·미완료 작업을 저장한 뒤 사용자 지시에 따라 pause한다. 사용량 비율과 잔여 비율을 혼동하지 않는다.
- 일부 경로가 막히더라도 독립적인 구현·검증은 계속하며 해당 경로만 후속 재검토한다. 현재 세션의 최신 usage event를 읽어 확인 가능한 수치를 사용한다.

## 순서와 작업 분리

1. **기기 보존 및 현황 확보**: 연결된 S24의 원래 화면 설정을 기록하고 임시 화면 설정을 적용한다. 앱 실행·업데이트 전에 센서 파일·환경설정·외부 정원 저장본·로그를 백업한다. 현재 최신 APK를 데이터 유지 업데이트로 설치하고 기록의 연속성·중단 사유·건강 데이터의 최신성을 분석한다. 연결 불가 시 재시도 근거를 남기고 A7으로 구현 검증을 진행한다.
2. **자료와 설계**: 제공된 PPT 또는 기존 저장소의 해당 기획 근거를 찾아 알림·개인화 요구를 확인한다. 현대 앱의 실제 공개 스크린샷을 인터넷에서 조사하고 탐색·실습·주 행동 배치를 분석한다. 출처와 적용 결정을 문서화한다.
3. **활동 UX**: 미션 소개·실습 화면의 안내/입력만 스크롤하고 진행·중단 동작은 고정 하단에 배치한다. 목록 이동, 잠시 쉬기, 종료의 의미를 분리하고 불필요한 동시 버튼을 줄인다. 나머지 주요 화면도 행동 위계·간격·중복 설명을 검토한다. 긴 한국어·키보드·가로 화면·뒤로가기·저장 복원을 검증한다.
4. **건강 기반 개인화와 알림**: 수면 및 평소 활동량의 기간 집계를 읽어 강도 조절 가능한 미션에 적용한다. 데이터 부족·미지원·권한 거절·오래된 데이터에는 명확한 기본값을 사용하며 시작한 활동의 목표를 중간에 바꾸지 않는다. 현재 정책과 저장본을 호환한다. 오늘의 활동 추천 및 걷기 달성 알림을 예약하고 중복·완료·거절·재부팅·시간 변경을 처리한다. 수집 상태 알림 대신 사용자에게 필요한 알림을 중심으로 구성하되 Android 필수 foreground-service 알림은 플랫폼 제약을 확인하여 수집 구조와 함께 해결한다.
5. **정원 모델과 환경**: 공식 Kenney 자산과 라이선스를 확인하여 둥둥섬 지형부터 식물·나무·동물·가구·장식까지 모든 3D 모델을 목록화하고 일관된 로우폴리 스타일로 교체·재구성한다. 일부 가구만 바꾸는 범위로 축소하지 않는다. 실제 렌더러 바닥 경계와 배치 공간으로 접지·겹침을 고친다. 현지 시각에 따라 태양·달, 낮 하늘·별, 움직이는 구름 및 방향광 그림자가 바뀌게 한다. 모바일 성능을 고려하며 시간을 주입해 낮·해질녘·밤을 검증한다.
6. **통합과 배포**: 변경별 도메인·네이티브·Unity 테스트, 다양한 화면 크기 캡처와 Vision 검토를 수행한다. 대부분의 합성 상태·반복 로그 작업은 A7에서 수행한다. S24는 기존 데이터를 보존하는 설치·짧은 실제 동작 검증에 사용한다. 작업/기기 사용 종료 시 화면 설정을 원래대로 복구하고 확인한다.
7. **저장소 동기화**: 완료된 논리 변경별로 소스·문서·자산과 라이선스를 검토하고 worktree 및 staged 개인정보 스캔을 통과한 뒤 커밋한다. 현재 upstream으로 일반 push하고 원격 HEAD를 확인한다.
8. **추가 요청 — 전체 화면 정원 배경**: 홈·정원의 3D 렌더를 카드에서 화면 전체 배경으로 확장한다. 제목·활동 안내·하단 메뉴는 읽기 쉬운 표면 위에 유지하고, 섬은 UI 사이의 열린 공간에 맞춘다. 낮·밤 및 세 화면 비율의 Vision 검토, 탭 전환 시 카메라 중지·입력 경로, A7 최종 설치와 데이터·화면 설정 보존을 확인한 뒤 동기화한다.

- 시작 상태: `01d7257`, 작업 트리 깨끗함. 이전 UI 후속 작업은 완료되어 있으며 이번 요구의 고정 실습 조작부·개인화·알림·환경 작업은 별도 구현 및 검증이 필요하다.

- 첨부 PDF 「캡스톤디자인(1) 2조 - 마음의 정원」 수신·읽기 완료. 원본은 저장소 밖에 있고 추출·렌더는 비공개 artifacts에만 둔다. 알림 전송/클릭 시각 차이로 시간 적응, 활동량 기반 가변 과제, 비진단적 건강 정보 활용, 처벌성 알림 배제의 기획을 확인했다. 최신 사용자 요청의 목표 예시와 범위가 과거 발표 숫자보다 우선한다.
- S24의 기존 ADB 연결에서 사전 백업 후 직전 검증 빌드 `01d7257`을 데이터 유지 설치했다. 설치 해시·실행 전 저장본 보존을 확인하고 가속도 기록 중단 원인을 분석했다. 화면 꺼짐·밝기·자동 밝기 원복 검증 완료. 새 통합 변경의 최종 빌드 설치와 검증은 별도로 남아 있다.

- 활동 본문/고정 조작부와 길이에 따른 배치를 구현했다. 합성 UI 144장 오버플로 0건, 스크롤 전후 하단 12쌍 동일, 선택 취소·입력 건너뛰기 회귀 포함 Unity 31/31 통과. Editor Play의 fresh/restore 및 실제 EventSystem 버튼 판정 6개도 통과했다. 새 동적 버튼은 명시적 RenderTexture 렌더 후 검사했으며, 실제 Android 키보드·터치와 최종 APK 검증은 별도로 남아 있다. [조사·적용 근거](ACTIVITY_UI_REVIEW_2026-10-12.md).
- 개인화 및 알림의 도메인·JVM 검증을 통과했고 별도 A7 패키지에서 건강 권한 없이 실제 알림 표시·PendingIntent·중복·설정·취소·재예약·완료 ACK 34항목을 검증했다. [정책·검증·실행 제약](ACTIVITY_NOTIFICATIONS.md).
- Kenney 공식 3개 팩의 원본 29개와 CC0 표기를 보존해 전체 정원을 재구성했다. 12종 발 높이·4모서리 지지·상호 배치·최대 성장 식물 이격 검증, 성장 4단계·회전 6방향·시각 5개 등 35장 시각 검토를 완료했다. 구름 24개 이동과 그림자 ON/OFF의 실제 픽셀 밝기 차이, 시각별 원반과 광원 방향 일치를 확인했다. [모델 목록·출처](../Assets/Art/External/KenneyGarden/README.md).

- 독립 검토에서 자동 걷기 완료의 선택 회고 손실, 발송 직후 달성 알림 삭제, 걸음 조회에 따른 다른 실습 입력 재렌더 손실을 발견해 수정했다. 완료 ACK와 명시 취소를 분리하고, 최신 입력 저장 성공 후만 화면을 다시 그린다. JNI 조회 응답이 사라지면 45초 뒤 재시도한다.
- 통합 APK 빌드 성공 후 A7에 데이터 유지 설치하고 설치 해시·실행 전 환경설정·과거 센서 기록·정원 저장 보존을 확인했다. 네트워크 단절로 미뤘던 완료 ACK 포함 실제 Android 알림 34항목도 재연결 후 통과했으며 별도 테스트 패키지를 제거했다.
- A7 실기기에서 키보드 위 입력·고정 버튼, Back 1회의 키보드 닫기와 초안 유지, 쉬기·재개, 최신 설정 카드를 확인했다. 키보드를 닫은 뒤 시스템 내비게이션 바가 앱 탭 카드 아래쪽을 가리는 결함은 Android 시스템 바와 Unity 안전 영역을 함께 반영하여 수정했다. 수정 APK에서 키보드 닫기·재열기·홈/설정 전환·백그라운드 복귀를 재검증해 탭 전체 노출과 입력 보존을 확인했다. 앱은 세로 고정이므로 가로 구성은 Editor에서만 검증했다. MOCK 저장을 정리한 뒤 실제 정원 저장의 바이트 일치를 확인했다.
- S24와 A7의 화면 설정은 원복 검증을 마쳤다. 중간 연결 단절 시 보존한 A7 복구 저널을 재연결 직후 먼저 처리했으며, 기기 검사에서 임시로 바꾼 회전 설정도 복구했다. 원본 저널·개인 기록·실기기 캡처는 계속 비공개로 보존한다.
- 검증된 통합 구현은 `816384d`로 커밋하고 현재 upstream에 일반 push했으며 원격 HEAD 일치를 확인했다. 후속 실기기 수정과 검증 문서도 같은 개인정보 검사·동기화 절차를 따른다.
